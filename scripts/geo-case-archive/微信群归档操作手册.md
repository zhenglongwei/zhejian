# 微信群 → 相册：操作说明

> 师傅只做复制 / 选图。不装微信群机器人（封号风险）。

## 路径 A：复制粘贴（主力）

1. 电脑微信打开这一单相关消息，多选 → 复制。
2. 打开辙见小程序门店端「微信转案例」→ 粘贴。
3. 点生成，核对抽出的主诉 / 发现 / 方案。
4. 一次选进本单照片，按格子挂到检查 / 施工 / 完工。
5. 去时间线补金额、核对后再通知车主。

不要用「合并转发」（折叠卡片拿不出文字）。

语音：手机长按 → 转文字 → 把文字补进粘贴内容。图片文件不会随复制进来，必须另选。

## 照片

从相册一次选多张（可分批）。工具按群里说话的顺序建议挂到哪一步，挂错点那张改。

电脑微信另存文件夹拖入是代录增强，本期不做。
