# geo-case-archive · 微信群归档转案例

> 2026-09-18 起：这是**小程序门店端的进料口**，不是独立九段文章生成器。  
> 口径：[`docs/04_维修过程相册/24_微信转案例迁入小程序.md`](../../docs/04_维修过程相册/24_微信转案例迁入小程序.md)

## 怎么用

1. 打开辙见小程序 · 新建相册 → **从聊天创建**。
2. 从电脑微信复制这一单群聊（纯文本）粘贴进去。语音先在手机里转成文字再贴。
3. 生成后会新建一本相册，并预填主诉、发现、方案、施工说明。
4. **一次选进**本单照片，按建议挂到检查 / 施工 / 完工，挂错点一下改。
5. 去现有时间线核对、补金额，再通知车主或托管。

官网首页工具区「从聊天创建」正文下放直达小程序码，扫开工具页；不再在网页里转换，也不再经过 `/archive` 说明页。

本地调后端：

```bash
cd backend
node scripts/smoke-wechat-archive.js
WECHAT_ARCHIVE_SMOKE_LLM=1 node scripts/smoke-wechat-archive.js
```

## 红线

- 先打码再送大模型；群里没说的不写；金额可进方案确认，不进公开概况。
- 不做规则抽字段、不做群机器人、不用合并转发。
- 对外来源只写商家上传，不写「沟通记录转化」「已审核」。
