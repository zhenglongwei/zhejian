# 2026-11-17 交车报告合并「已施工」与「验收」为一张清单

> 状态：生效
> 生效：2026-11-17

## 1. 变更

| # | 旧口径 | 新口径 |
| --- | --- | --- |
| 1 | 交车报告分两个区块：**已施工**（工单项目 + 用料 / 品牌 / 数量 / 金额 + 施工图）与 **验收**（同名行 + 结果 + 验收描述 + 同一批施工图） | 合并为一张 **「施工与验收」** 清单：一行 = 项目名 + 施工说明 + 验收结果 + 验收描述 + 用料 / 品牌 / 数量 + 图片；外观行仍固定最后一行 |
| 2 | 同一项目名和同一张施工图在两个区块各出现一次 | 同一项目、同一张图只出现一次；验收区不再独立成章 |
| 3 | 数据侧两项各自渲染，读侧按字段分别取 | 展示层按行名合并 `workItems` 与 `acceptanceItems`；**数据不迁移**，两个数组仍各自保留，合计、返工记录、质保、确认条款不变 |
