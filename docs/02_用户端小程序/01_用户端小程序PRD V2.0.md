### **1.1 平台身份（V2.0）**

平台**不是**：交易平台、维修服务提供方、统一报价方、维修质量担保方、售后赔偿主体。

平台**是**：**服务相册工具**、咨询预约与 **用户主导发布** 留痕工具、门店分享链路的 **私域承接端**；**GEO / 公开案例获客主战场在站外**（H5、公众号）。

统一说明（服务页、门店页、案例页、咨询页、相册页均需展示）：

> 平台提供门店信息展示、维修案例展示、服务相册、咨询预约和隐私脱敏工具。实际维修服务、检测报价、收款、发票、质保和售后由门店线下提供和承担。案例内容由门店上传或经用户授权后展示，仅供参考，不构成平台报价、维修承诺或质量保证。

## **2. 产品目标**

1. **看得懂**：看懂服务项目、价格影响因素、类似案例与维修过程。
2. **敢选择**：通过门店资质、脱敏案例、服务相册建立信任，降低不透明担忧。
3. **有档案**：线下维修后通过服务相册留存过程与确认记录；可对本次服务评价。上网由商家托管。

V2.0 **不做**：在线下单、微信支付、订单履约、完工确认、交易评价奖励、售后仲裁。

## **3. 核心闭环**

### **3.1 小程序内（工具闭环 · 2026-06-08 起优先）**

```text
用户进入小程序（微信搜索 → 工具首页 / 商家分享 → 深链直达）
→ 扫码或打开「我的服务相册」
→ 查看服务相册记录
→ 可选：对本次服务评价
```

车主端**不做**：留言咨询、授权公开、从店页撤下、分享相册。上网由商家托管。

### **3.2 站外（公域获客闭环 · H5 / 公众号）**

```text
授权案例审核通过 → H5 案例页 / 公众号文章 / GEO 收录
→ 站外浏览与搜索 → 咨询/电话 → 线索回流该门店
→ 到店服务 → 商家创建服务相册 → 回到 §3.1
```

### **3.3 历史 V2.0 发现闭环（仅深链兼容 · 待下线）**

原「首页搜索 → 浏览服务/案例/门店 Tab → 咨询」路径仍保留路由，**不再** 作为冷启动首页与主导航（见 `02_工具入口首页.md`、`08_双系统转型开发计划.md` 阶段 A/D）。

## **6. 咨询与预约（摘要）**

- 入口：服务详情、案例详情、门店详情、GEO 页。
- 按钮文案：联系门店、预约到店、咨询报价、提交咨询（禁用：立即购买、提交订单、在线支付）。
- 提交前须勾选：已知晓实际维修服务由门店线下提供。
- 事故车须额外勾选：需到店检测后由门店报价；平台不提供线上最终报价。
- 详情见 `05_咨询与到店预约.md`。

## **7. 我的模块（摘要）**

**我的咨询**：状态仅 `已提交 / 门店已查看 / 门店已联系 / 用户已取消 / 已关闭`，不做订单态。

**我的服务相册**：来源包括门店手机号关联、相册链接、扫码、用户认领；展示门店、脱敏车辆、服务项目、相册状态、是否已公开。

详情见 `06_咨询记录与我的相册.md`。

## **8. 服务相册查看（摘要）**

- 从「订单相册」改为「服务相册」；入口：我的服务相册、门店分享链接、扫码。
- 六阶段时间线 + 配件确认卡 + 待确认集中处理。
- 车主查看服务进度并对本次服务评价。上网由商家托管；车主端不授权、不分享、不从店页撤下。

## **10. 案例上网（修订 2026-09-17）**

> **口径真源**：`19_商家发布案例上网口径.md`、`00_Phase1_服务相册产品口径.md` §4 / §4.5。

### **10.1 发布到公开网站**

- 案例来源：**门店托管发布**的打码施工记录；遗留 **商家历史案例** 标签（无「平台订单案例」）。
- **仅商家**生成并送审；人审通过后出现在 **H5 / 站外 GEO**（**不含** 小程序案例 Tab）。
- 车主端**不**授权公开、**不**从店页撤下、**不**分享相册。相关页仅保留深链。
- **过审即上店页**；平台不代发即将上网通知。
- 公开展示 **强制脱敏 + 合规审核**（非维修质量/六阶段质检；见 `04_公开案例审核.md` §9.3）。

### **10.2 发给微信**

车主端不下发分享入口。商家仍可把相册链接发给车主查看。深链页保留。

### **10.3 合规**

- V2.0 不做评价奖励、分享领钱类诱导。

## **13. P0 验收标准**

### **13.1 工具化首页（2026-06-08 增补 · DS-A-02）**

1. 微信搜索冷启动见 **工具入口首页**（`02_工具入口首页.md` §14），无跨店推荐；
2. Tab 目标态为 **首页 + 我的**（服务/案例/门店 Tab 不暴露）；
3. 扫码 / 相册码 /（未登录）我的服务相册入口可用；**已登录相册摘要在「我的」**；
4. 提供 H5 内容站出口；分享深链仍可直达相册/门店。

### **13.2 通用能力（保留）**

1. 用户可微信登录、绑定手机号；
2. 可通过 **深链** 浏览服务/门店/案例详情并搜索（非冷启动主路径）；
3. 可查看服务/门店详情（含资质、案例；底栏联系门店拨打电话）；
4. 可查看公开脱敏案例（**站外 H5 为主**；小程序详情页深链兼容）；
5. 小程序车主端不提交留言咨询；H5 公开站仍可留言，线索进商家工作台；
6. 可通过链接/扫码查看私密服务相册；
7. 可在我的服务相册中查看已关联相册，并对本次服务评价；
8. 门店可将打码施工记录托管上网；车主端不授权、不撤下、不分享；
9. **站外** 可生成服务/案例/门店/车型/故障相关 GEO 页面（小程序 GEO Tab 非 P0）。
