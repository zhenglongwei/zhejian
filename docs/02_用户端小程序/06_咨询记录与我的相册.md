## **3. 我的服务相册**

> **2026-09-08 修订**：入口仍可叫「我的相册」；点进详情后主阅读为 **服务进度**（单据时间线），不是照片流。真源见 [`23_面向车主单据与确认件.md`](../04_维修过程相册/23_面向车主单据与确认件.md) §5 与 `07_维修相册查看页.md` 文首现行口径。

用户可查看门店为其创建的 **服务相册**；列表保留相册入口心智，**详情以报告/确认单据为主**。

**来源**：门店建档手机号（须与登录手机号一致）；商家分享链接；扫码（P1）。

**列表 Tab（2026-08-01 修订）**：**全部** / **进行中** / **已完工**（三 Tab；**不再**按「是否公示」分档，也**不再**单独保留「授权公示」页）。

> **分界**：以平台 **案例审通过** 为界（门店确认完工后唯一阻塞审；只审一次）。通过前 → **进行中**；通过后（含已发布、撤回后再发免审）→ **已完工**。  
> **发布到公开网站** 经分享面板触达，**不**作为列表分类标准。

| Tab | 筛选规则 |
| --- | --- |
| **全部** | 所有服务相册 |
| **进行中** | 尚未案例审通过（维修中、脱敏中、审核中、驳回/需修改后重提等） |
| **已完工** | 已案例审通过及之后（`review_passed`、`public_approved`、撤回后的 `offline`） |

**列表卡片（2026-09-18）**：

| 行 | 规则 |
| --- | --- |
| 封面 | **保留**缩略图（证据图或商家封面） |
| 1 | **车牌号**（脱敏）；无牌「未登记车牌」。禁止用进度或类目当标题 |
| 2 | 服务类目 |
| 3 | 服务商 |
| 4 | 品牌车型 |
| 5 | 服务进度（进行中 / 施工中 / 待确认方案 / 已完工等） |

**卡片操作**：可评时右上 **去评价 / 追评**；点卡片进详情。不下发授权公开、从店页撤下、分享。

**下载档案（2026-07-25）**：列表页底栏固定 **下载档案** → 进入单选模式 → 点选一本相册 → **确认下载**，打包全部原图 ZIP（按节点名命名）。仅关联车主；详情见 `07_维修相册查看页.md` §10.2。

**禁止**在列表使用面向内部的文案：「可授权」「已授权」「已公开」「待授权公开」等。

详情 = **服务进度**（单据竖向时间线）；见 `07` 文首现行口径与 `23` §5。

**列表字段**：车牌、服务类目、服务商、品牌车型、服务进度。不展示送修日期、张数、待评价 Tag。可评时右上按钮进 `pages/album/engage`。

**触达**：不依赖「相册照片更新」订阅消息；待确认靠门店线下告知或分享进进度页。绑定规则见 `23` §5.6。

详情与授权公开见 `07_维修相册查看页.md`。

### **3.1 配件验真（入口摘要）**

- 路径：`pages/album/part-verify/index`  
- 入口：详情尾页 / 底栏 / 抽屉  
- 作用：对照 **方案 `planParts`** 与 **相册 `partsJson`**（名称、类型、品牌、编码）；**不鉴定** 真伪

### **3.2 服务评价（入口摘要 · 2026-07-31）**

- 路径：`pages/album/engage/index`  
- **可评**：完工 + 平台案例审通过（与车主可看整本相册同条件）  
- 入口：详情尾页 / 底栏「评价」/ 列表与「我的」Hero 卡 **右上**「去评价 / 追评」/「我的」待办「N 本待评价」  
- 表单：维修服务 + 相册记录四维打星（必填）+ 可选标签 / 文字 / 配图；**无**评价现金奖励

## **5. 与咨询的关系**
