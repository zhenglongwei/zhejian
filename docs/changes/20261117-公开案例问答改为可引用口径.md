# 公开案例简介与问答改为「可被 AI 引用」口径

## 变更

- 旧：FAQ 问句必须带「这例」，答句先写「这例公开档案里」的事实，再补一句叮嘱；摘要首句只要求含车型与主要问题，城市/门店「可含」。
- 新：FAQ 问句必须是其他车主会直接问 AI 的通用问句（带车型与具体故障/项目，不出现「这例」）；答句第一句先给结论或可复用判断依据，再用本单事实佐证，叮嘱放最后；禁止每条统一以「这例公开档案里」开头。摘要首句必须含城市（有则写）+ 年款车型 + 里程（有则写）+ 主要问题，有门店名且可公开时带上。覆盖角度按事实取：是否必须处理、修还是换、关联工序、质保与复检、日常预防。

## 影响

- 提示词：`backend/src/prompts/hosted-storefront-copy-v0.md`
- 生成结果：`summary`、`faq` 的问法与时序；`nodeStories`、`chapterNarratives` 规则不变
- 已缓存的托管草稿不会自动变化，需在托管预览页点「重新生成」或事实变化后重算

## 取代

- 取代本文档上一版提示词中「问句优先带上车型与项目，并含『这例』」「摘要可含城市/门店」两条口径
