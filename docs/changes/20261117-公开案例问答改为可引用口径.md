# 公开案例简介与问答改为「可被 AI 引用」口径

## 变更

- 旧：FAQ 问句必须带「这例」，答句先写「这例公开档案里」的事实，再补一句叮嘱；摘要首句只要求含车型与主要问题，城市/门店「可含」。
- 新：FAQ 问句要么是其他车主会直接问 AI 的通用问句（问故障/项目/养护本身，不出现「这例」），要么是真属于该车型/年款的问题；**不把通用问题硬加车型说成「这款车专属」**。答句按三层写：①先答通用层（行业通行做法、常识性判断标准、通行的质保/流程原则，不默认限定车型）；②车型层（该年款确有特殊性才写，没有就跳过）；③本单层（用本单已确认事实佐证）。费用同样分层：先说行业常见量级（标明非本店报价），再说本单构成与合计，本单金额只能来自 `facts.quotePricing` / `addonQuotePricing`。禁止编造法条编号或条款原文。摘要首句必须含城市（有则写）+ 年款车型 + 里程（有则写）+ 主要问题，有门店名且可公开时带上。覆盖角度按事实取：是否必须处理、修还是换、关联工序、质保与复检、日常预防。

## 影响

- 提示词：`backend/src/prompts/hosted-storefront-copy-v0.md`
- 生成结果：`summary`、`faq` 的问法与时序（答句由「结论+本单佐证」改为「通用层→车型层→本单层」）；`nodeStories`、`chapterNarratives` 规则不变
- 已缓存的托管草稿不会自动变化，需在托管预览页点「重新生成」或事实变化后重算

## 取代

- 取代本文档上一版提示词中「问句优先带上车型与项目，并含『这例』」「摘要可含城市/门店」两条口径
