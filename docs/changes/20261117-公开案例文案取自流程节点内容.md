## 1. 变更

| # | 旧口径 | 新口径 |
| --- | --- | --- |
| 1 | 托管时归档快照只冻结流程节点的 `photoDraft` / `document.payload` | 归档快照同时冻结 `content`（单据人工文本真源）；`photoDraft` 仅作旧数据别名 |
| 2 | 公网档案取单据链时，`archiveSnapshot.flowNodes` 只要存在就整份使用，哪怕节点没有文字 | 归档节点缺人工文本时，按节点 `id` 从相册当前 `contentPackageJson.flowNodes[].content` 回填；归档已有文字仍以归档为准（不上网内容不被改） |
| 3 | 公开事实 `facts`（`faultDesc` / `inspectResult` / `repairPlan` / `resultConfirm`）从旧 `stage_*` 节点 `note` 提取，流程相册恒为空 | 优先从流程节点 `content` 提取：诉求取 `chiefComplaint`；检测结论取 `findings[].partName + result`；方案取 `lines[].name(+brand)` 与 `work.findings[].caption`；完工取 `acceptanceItems` + `warrantyPeriod/warrantyNotes`。无流程节点时才回退旧 `stage_*` |
