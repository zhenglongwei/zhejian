# 2026-11-17 交车报告改为「交车凭证」

> 状态：生效
> 生效：2026-11-17
> 适用：`repair_report` 报告正文 / 车主端服务进度 / 商家端报告预览

## 1. 变更

| # | 旧口径 | 新口径 |
| --- | --- | --- |
| 1 | 交车报告是一张「施工与验收」合并清单：施工项逐行 + 验收结果 + 用料 / 品牌 / 数量 + 合计金额 + 返工记录 | 交车报告只做**交车凭证**：整车外观照、交车里程、交付人、交车时间、施工时长、质保（期限 / 注意事项） |
| 2 | 验收、返工、未施工交代、合计金额都放进交车报告 | 这些内容已在施工节点 / 施工报告中体现，交车报告不再重复；施工报告继续写施工节点的人（`workerName`），交车凭证写交付节点的人（`delivererName`） |
| 3 | 车主直接确认，不提示回看前序报告 | 增加「本次维修相关报告」入口（接车报告 / 检测报告 / 报价单 / 补充报价单 / 维修工单 / 补充施工），提醒确认前先查看，点击直接打开对应报告 |
| 4 | 已冻结的旧交车报告读 `renderDoc` 快照，旧报告保留旧样式 | 交车报告渲染不再读 `finish` 快照，车主端与商家端统一从节点 `content` 现场构建，旧报告也切换为新凭证样式 |
| 5 | 页眉同时拼接接车里程与交车里程 | 页眉只写交车里程 |

`repair_report.content` 数据保持全量：`workItems`、`acceptanceItems` 继续写入并保留，公开 / 托管完工章与商家 `buildFinishPayload` 仍依赖它们；本次只改交车报告的展示。
