# 公开案例报价金额改为明码展示

## 变更

- 旧：公开案例的报价行只保留项目名，`amount` 一律不进入公网章节、AI 原料与结构化数据（藏价口径）。
- 新：已确认报价行的 `amount` 明确展示——公开章节 `items[].amount`、托管文案原料 `facts.quotePricing` / `facts.addonQuotePricing`（含明细与合计）、公开页 JSON-LD `facts.quoteItems[].amount`。金额为 0、缺省或非数字时不展示；模型只能引用这些确定性数字，禁止编造折扣、工时拆分或未给出的金额。

## 影响

- `backend/src/utils/public-service-flow.js`：报价行输出 `amount`
- `backend/src/utils/case-geo-factpack.js`：新增 `quotePricing` / `addonQuotePricing`（按项目名去重取最后一次报价，合计为明细之和）
- `backend/src/services/case-hosting.service.js`：把上述金额注入托管文案原料
- `backend/src/lib/case-facts-jsonld.js`：JSON-LD facts 带项目金额
- `backend/src/prompts/hosted-storefront-copy-v0.md`：允许引用金额并限定来源
- 小程序 `components/host-archive-preview`、H5 `h5/shared/case-render.js`：项目名右侧展示 `¥金额`

## 取代

- 取代旧「公网侧不带金额」口径（原 `case-geo-factpack.test.js` 的 `testNeverFeedsAmount`）
