# 2026-11-17 商家端服务相册报告入口按节点独立绑定

> 状态：生效
> 生效：2026-11-17

## 1. 变更

| 旧口径 | 新口径 |
| --- | --- |
| 顶部固定生成五张报告入口（接车、检测、报价单、维修工单、交车），同类型报告共用入口，预览时按"当前点击节点"推断内容，易串到其他节点 | 每个报价/施工节点生成独立入口，报价单绑定首报节点、补充报价单绑定各自补充节点、维修工单/补充施工/返工施工各自独立；摘要、预览、发送统一使用入口自己的 `nodeId`，不再受当前点击节点影响 |
