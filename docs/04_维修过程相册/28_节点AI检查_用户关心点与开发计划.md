## 0. 先说清三件事

**谁在问。** 同一份档案要同时经得起三种看：

| 谁 | 真正要什么 |
| --- | --- |
| **本单车主** | 门店有没有乱加项目；查了什么、为什么做、做成没有、质保怎么说 |
| **以后来搜的人** | 和我车、我现象像不像；有没有能核对的证据（厚度、规格、新旧件），不是广告句 |
| **要引用的模型** | 城市 + 人话车型 + 里程 + 现象 + 结论 + 做法 + 结果；禁止编造、禁止百科、禁止金额 |

**检索词 ≠ 案例该答的题。** 人会搜「刹车片多久换一次」——那是百科。一条真实档案只该回答：**这台车这次片还剩多少、换没换盘、试车怎样**。模型给店员的优化方向，只补本单能核对的事实，不补「一般多久换」。

**类型只换提纲，不换计费逻辑。** 成本和等待看本步新图张数、提交次数；类型只决定「这一步该盯哪几件事」。

## 1. 各类型共性（所有类目都要）

人/模型几乎每单都会对这几句：

- 车主为什么来（现象，不要只写「保养」）
- 到店里程、人话车型（品牌 + 车系 + 年款）
- 做成了哪几项（和检测建议对得上）
- 结果或质保（有写才引用；「以门店公示为准」不算）

各步共同的优化方向（缺则建议，**不硬拦**）：

| 步骤 | 缺图时建议拍 | 文本问题时给可填句 |
| --- | --- | --- |
| 接车与检测 | 仪表里程（表盘入镜、不要导航轨迹）；整车/相关方位外观（不要微信码、名片） | 主诉改成现象句；发现项改成「部位 + 结论 + 建议」 |
| 施工 | 本单做成项的证据：包装/规格、新旧对比、安装到位 | 图注写「本图证明什么」（规格 / 已更换 / 力矩） |
| 完工 | 车身全貌（不要码）；与主项相关的复查图 | 质保写成时长或里程；针对主诉写复查结论 |
| 核对报告与方案 | 一般不再要新图 | 主诉与主项是否同一件事；方案行名是否就是部位；**不改金额、不编项目** |

工单只读，不跑模型。增项多轮保留，模型不得建议「合并成一条链」。

## 2. 分类目：检索关心什么 → 各步盯什么

下列「检索/问法」是人进搜索框或问 AI 的说法；「本单该留下的」才是优化方向。检查项名称与 `17_` 对齐，便于模型对照清单，不另造一套部位名。

### 2.1 小保养

**人会搜 / 会问：** 小保养包括什么、机油用什么规格、换没换机滤、空调滤这次做不做、下次何时做、多少公里做的。  
**真正要核对：** 这次换了油和滤没有、规格是什么、哪些巡检正常/没做、下次保养建议。

| 步骤 | 缺图（拍哪、怎么拍） | 文本（给可直接用的句） |
| --- | --- | --- |
| 接车与检测 | 仪表；环车；旧机油颜色/液位；机舱液位（刹车油/防冻液储罐 MIN–MAX）；轮胎目视。大灯点亮、底盘举升有做再建议补 | 主诉写成「到店保养，里程 ××」或具体异响/漏油。旧油：颜色/杂质 + 是否建议更换。空调滤：本次套餐含不含、脏污程度 |
| 施工 | 新机油桶标（规格入镜）；新旧机滤；加注后油尺/窗。换了空调滤则新旧滤同框 | 「规格 ××，品牌 ××，机滤一并更换；液位在标尺正常区间」 |
| 完工 | 出场外观；可选胎压枪读数 | 「建议下次 ×× km 或 × 个月（按手册与用车环境）」 |
| 核对方案 | — | 方案项应是机油/机滤等部位名；巡检正常的不要预填报价行 |

### 2.2 大保养

**人会搜 / 会问：** 大保和小保差在哪、空滤火花塞换了没、变速箱油/正时这次动了没。  
**真正要核对：** 小保那些都做了没有 + 本次增量做了哪几项、没做的一句原因（车型没有 / 未到周期）。

在小保养各步之上再盯：

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 打开空滤盒；皮带张紧段；若检火花塞则旧件电极；有油液深度检则储罐/取样 | 空滤/火花塞/燃油滤：已检已换或跳过原因。正时：已核对手册，未到或建议专项（禁止「必须换」） |
| 施工 | 空滤/火花塞新旧对比；若换刹车油/防冻液则过程或新液 | 写清「本次大保增加项：……；未做：……（原因）」 |
| 完工 | 功能抽检（启动/怠速/空调吹风） | 与小保相同的下次保养建议 + 抽检正常与否 |
| 核对方案 | — | 增量项与检测建议一致；未做项不要出现在方案里充数 |

### 2.3 刹车片 / 刹车盘

**人会搜 / 会问：** 异响是不是片、多久换、盘要不要一起换、换完要磨合吗、电子手刹怎么拆。  
**真正要核对：** 片厚/盘厚数字、盘面状态、换片还是片+盘、哪一根轴、试车还响不响。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 游标/测厚读数入镜（片、盘）；盘面近景；软管接头；卡钳打开时的导销 | 主诉：异响/抖动/行程变长/常规检查。片厚「前/后外侧约 ×mm，建议更换或可暂缓」。盘「剩余 ×mm，换盘或暂不换」。更换范围：仅片 / 片+盘，哪一根轴 |
| 施工 | 新片/盘规格面；旧新同框；力矩扳手打卡；有 EPB 则维修模式仪屏（脱敏） | 「按规范力矩；本次开/不开油路（开则已排气）」 |
| 完工 | 储液罐液位；可选试车无关违规画面 | 试车：异响/踏板/抖动结论。磨合注意点（勿保证永不异响） |
| 核对方案 | — | 行名是「前刹车片」这类部位，不要「需处理」；盘不换要在建议里写清 |

### 2.4 电瓶更换

**人会搜 / 会问：** 打不着是不是电瓶、AGM 能不能换普通的、要不要匹配、质保几年、换完还亏电怎么办。  
**真正要核对：** 检测读数、桩头有没有排除接触不良、规格（AGM/EFB/铅酸、Ah）、启停是否核对、启动是否恢复。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 检测仪电压/内阻或负载（VIN 勿清晰）；旧瓶日期码；桩头腐蚀近景 | 主诉：启动困难/亏电/无法启动/启停异常。结论：「建议更换 / 可充电观察」+ 读数。反复亏电：本次未测暗电流或建议复查用电 |
| 施工 | 新瓶规格标签；新旧同框；压板与桩头极性 | 「型号×× 容量××Ah；本车需要/不需要匹配，已处理或无需」 |
| 完工 | 启动或启停抽检相关（勿拍人脸） | 启动正常与否；质保时长与条件（禁绝对化） |
| 核对方案 | — | 不要把「打不着火」直接写成一定是电瓶；方案就是电瓶更换，充电系统待复查写在建议里 |

### 2.5 轮胎更换

**人会搜 / 会问：** 要不要四条一起换、偏磨要不要定位、规格能不能改、TPMS、周号新不新。  
**真正要核对：** 换几条、哪几个位置、花纹/鼓包证据、规格一致、动平衡和胎压、定位做了没。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 胎面近景（有参照）；胎侧鼓包/裂纹；相关方位（少拍清晰车牌整车） | 主诉：磨损/鼓包/扎胎/偏磨/抖动。更换条数与位置。偏磨则「建议定位 / 本次不做定位及原因」 |
| 施工 | 新旧胎侧规格字；DOT 周号；动平衡过程或界面；胎压枪；轮毂力矩打卡 | 规格/负荷/速度级；气门嘴换新或沿用；TPMS 转移或换新、是否学习 |
| 完工 | 装车后轮圈外观 | 磨合期胎噪/路感已告知 |
| 核对方案 | — | 禁止「必须四条一起换」恐吓句；同轴规格不一致要写约定 |

### 2.6 空调服务

**人会搜 / 会问：** 不制冷是缺氟还是坏了、异味要不要洗箱、滤芯脏不脏、冷媒型号。  
**真正要核对：** 诉求是不制冷/异味/风量/换滤中的哪一种；滤芯状态；压力/检漏有没有做；实际路径是换滤、清洗还是补冷媒。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 抽出的旧滤特写；出风口；不制冷则冷凝器正面、压力表（脱敏） | 主诉必须分清四类之一。滤芯：脏污程度 + 建议换或暂用。处理路径一句。仅换滤/异味且不做冷媒作业：压力项可建议跳过并写原因 |
| 施工 | 新旧滤同框；若清洗则过程；若加注则加注可见点（勿拍金额单） | 冷媒类型（R134a / R1234yf）+ 已加注或未加注原因 |
| 完工 | 出风复查（可选温度显示） | 「出风变凉 / 异味减轻或仍在」如实写；换滤周期建议 |
| 核对方案 | — | 路径与诉求一致：异味单不要自动写成「必须洗箱」 |

### 2.7 钣喷修复

**人会搜 / 会问：** 会不会色差、喷一块还是连带邻板、钣金还是补漆、缝隙正不正、多久能碰水。  
**真正要核对：** 哪块板、损伤程度、修复路径、过渡范围、完工近远景和色差复查（如实，禁止 100% 无色差）。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 远景定位（车牌避开或待脱敏）；近景划痕/凹陷；漆膜仪读数入镜（损伤区 vs 邻板） | 部位名称（如右前门）。路径：局部补漆 / 整面喷 / 钣金+喷。过渡：本板或延伸邻板（无绝对无色差承诺） |
| 施工 | 打磨/腻子/中涂关键帧；遮蔽范围；材料包装无金额 | 工序按实际勾选描述；卡扣缺失须注明 |
| 完工 | 近景 + 远景；板缝面差；自然光过渡区 | 色差/缝隙如实。养护：暂勿高压水枪等 + 质保范围 |
| 核对方案 | — | 方案写清喷哪些板；不要写成「恢复原厂」 |

### 2.8 事故车维修

**人会搜 / 会问：** 结构件动了没、气囊爆没爆、要不要标定、修完灯和缝正不正。  
**真正要核对：** 碰撞方位、损伤清单、安全件/气囊客观状态、维修范围（更换 vs 修复）、ADAS/定位做了没。公域少金额、少未脱敏定损单。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 到店多方位损伤（避无关隐私）；结构/举升若做了则挂图；气囊灯/现场状态；诊断仪屏脱敏 | 损伤部位名称级清单。气囊是否起爆、气囊灯是否亮（勿恐吓）。范围：换哪些、修哪些（无价格） |
| 施工 | 主要更换件开箱或旧件；钣金/涂装关键帧；标定仪屏或报告（脱敏） | ADAS：已做 / 无需 / 待专项 |
| 完工 | 主要部位修后 vs 接车对照；灯光开合；定位结果无金额 | 气囊灯熄灭等抽检；质保与注意事项（无线上报价） |
| 核对方案 | — | 公开侧不要把定损金额带进说明；私域单据与公开文案分开 |

### 2.9 底盘异响 / 胶套

**人会搜 / 会问：** 过减速带响是什么、胶套还是轴承还是减震、换完还响吗、要不要定位。  
**真正要核对：** 何时响、复现了没、查了哪些并排除了什么、换了哪件、原场景路试结果。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 举升后胶套/球头/小吊杆近景；减震渗油或顶胶；轴承检查过程 | 主诉必须带场景：过减速带/转弯/刹车/冷车。已排除项（排气管、轮胎等）价值高。处理路径：压胶套或换总成及原因 |
| 施工 | 旧件开裂对照；压装/力矩打卡；配件包装 | 配件名称一句 |
| 完工 | — | 原异响场景路试：消失/减轻/仍存。动摆臂后定位：已做或未做原因 |
| 核对方案 | — | 方案对应查出的那一件，不要写成「底盘大修」 |

### 2.10 通用（未命中专用类目）

**人会搜 / 会问：** 这车出了什么问题、店里怎么处理的、处理好了没。  
**真正要核对：** 现象 → 查了什么 → 做了什么 → 针对诉求的复查。不要套用片厚、色差等专修句式。

| 步骤 | 缺图 | 文本 |
| --- | --- | --- |
| 接车与检测 | 仪表；环车；能说明结论的检测证据图 | 主诉一句话可核实。发现：现象 + 手段 + 结论（排除了什么）。作业范围清单 |
| 施工 | 关键工序；若换件则规格/包装 | 本图对应哪一步 |
| 完工 | 针对诉求的复查图 | 复查结论 + 使用注意（无绝对化） |
| 核对方案 | — | 建议切到专用类目（若服务其实是保养/刹车等）；方案行与发现一致 |

## 3. 模型输出长什么样（给店员用，不上车主屏）

每条建议只做两类，都不拦下一步：

1. **补图**：部位名 + 怎么拍（距离、要入镜的读数/标签、避码/避车牌）。  
2. **改句**：针对当前字段给出**可一键填入**的建议句（主诉、发现项建议、图注、质保、完工结论）。店员可改可不用。

禁止模型：编造没拍到的厚度/规格；改金额；把「需处理」写进方案行名；保证修好/无色差/全网最低；建议合并增项轮次；把百科问答当成优化方向。

关掉小程序后，打码与分析继续；再打开仍停在本步，直接展示已出的建议。

## 4. 整体开发计划

### 4.1 已拍板（本分析之前的共识）

- 每步确认前检查；车主看到的单据与公开档案同一事实源。  
- 先打码，只用打码图问模型。  
- 打码图和分析结果落库，托管不再整单重打、不再拿原图问模型。  
- 不硬拦：可「用这条」或「仍要继续」。  
- 必须先看到建议再决定；等待中可离开，后台不停。  
- 所有已有清单的类目都接；只限制**步骤**（接车与检测、施工、完工、通知车主前核对）。工单不跑。

### 4.2 分步（建议实施顺序）

| 序 | 做什么 | 验收 |
| ---: | --- | --- |
| 1 | 把本文 §2 收成「类目 × 步骤」检查提纲（程序可读，挂 `17_` 的 itemKey） | 小保养接车、刹车检测、电瓶施工 三组抽检：缺图建议含部位和拍法；空主诉能给出现象句 |
| 2 | 本步新图增量打码，任务可脱离小程序跑完；结果挂到该节点 | 关掉再进，已打码的图不重打；失败不把原图送给模型 |
| 3 | 打码完成后跑本步分析；建议结构化：补图 / 改句（字段 + 建议文本） | 店员「用这条」写回主诉或处理建议；「仍要继续」能进下一步 |
| 4 | 核对报告与方案：只对文字与项目对齐，不看新图、不改价 | 主诉与方案主项明显无关时给出改句；金额字段不被模型改写 |
| 5 | 托管向导：已打码图直接用；本单 FAQ/摘要只抽各步已确认事实 | 托管不再对同图二次脱敏；不把车主没见过的润色句写进已确认单据 |

界面：等待句只说「正在检查本步，可先离开」。建议列表短、商家口吻。不出现「提示词 / 自动优化 / 大模型」等实现话术。

### 4.3 本轮不做

### 4.4 能力开关（成本 · 前期全员免费）

大模型检查与自动脱敏都会产生费用。**必须留开关**，不要做成关不掉的默认路径。

| 闸 | 作用 | 前期默认 |
| --- | --- | --- |
| **总闸** | 关掉后，所有店本步「确认并继续 / 通知车主」走原来的直接确认，不排队打码、不问模型 | **开** |
| **套餐闸** | 关掉「要求付费」时全员可用；打开后仅指定套餐可用。未开通时本步直接确认，**不**弹出升级页（收费后再改提示） | **全员免费**（不要求付费） |
| **模型闸** | 关掉后仍可用规则提纲出补图/改句，不调大模型（费用更低，便于演练） | 跟随现有文本模型配置；没有密钥时自动走规则 |

原则：

- 前期给所有人免费用；以后视情况打开套餐闸再收费。  
- 关总闸或未开通 = 行为与做本能力之前一致。  
- 界面不出现「套餐 / 大模型 / 计费」等实现话术；收费后若要提示升级，另写商家短句。
