## 1. 产品目标

由相册生成的公开案例是辙见核心：在**真实、可核对**的前提下，**直接回答这单已经处理过的用户痛点**，供人和大模型检索、引用。

| 页 | 做什么 |
| --- | --- |
| 公开案例 | 一篇文章：要旨 → 本单问答 → 详情与打码图。商家生成时按此通读确认。 |
| 门店页 | 这家店的橱窗 |
| 类目文件夹 | 该店某一类目的案例数 + 链接。不跨店、不写合成文章 |

咨询只回该案例所属门店。

---

## 2. 禁区（实现时对照）

- 编造相册里没有的工期、贬值、质保、总成结论  
- 用通用 FAQ / 专题文凑检索  
- 公域写金额；原图进外部大模型；完工后加图  
- 只拼六阶段日志、不把痛点问句提到前部  
- 跨店专题、服务页比店、首页/城市「推荐门店」当产品能力保留  

---

## 3. 功能拆分与实施顺序

先做案例（核心），再做店内文件夹，最后拆掉不相干的公域壳。教练备注可并行，但不阻塞生成预览。

```text
A 生成预览（要旨 / 本单问答 / 详情）
    → B 公开案例页与生成稿同构 + 问答写入快照
        → C 门店页按类目分夹
            → D 清除历史公域壳（专题文、比店、跨店统计）
教练（完工前写清痛点）可与 A 并行，不挡 A
```

### 阶段 A · 生成案例（P0）

商家点「生成案例」看到的就是即将上网的文章。生成器从相册抽出**这单已有答案的用户问题**放到问答区。

| ID | 任务 | 说明 |
| --- | --- | --- |
| CASE-SRC-A01 | 生成页按文章顺序通读 | 要旨 → 本单问答 → 各详情节与图；不是三块互不相关的表单 |
| CASE-SRC-A02 | 本单问答抽取 | 从节点说明、检查项、交车备注抽用户问句；0 条合法；禁止 `DEFAULT_FAQ` / 模板凑 3 条 |
| CASE-SRC-A03 | 商家可删问答、不可编造 | 可改表述；不能手填相册没有的结论；不能加新图 |
| CASE-SRC-A04 | 确认稿含要旨+问答 | 送审 payload 带 FAQ；过审写入 snapshot，禁止事后 enrichment 改问答 |
| CASE-SRC-A05 | 上网标题 + 按工单抽问答 + 空章隐藏 | 标题一句人话；保养/维修不同问句；无内容章节不占版面 |
| CASE-SRC-A06 | 有证检查全貌进公开稿 | 查了 / 做了 / 有依据才写为何不同；不靠商家写长文；图不进外部模型 |
| CASE-SRC-A07 | 打开预览即写顺 | 默认润色；等写完再展示；失败回退规则稿；去掉「AI 润色」按钮 |
| CASE-SRC-A08 | 生成预览等打完码再展示 | 只展示打码图；失败不拿原图充数；施工相册仍看原图 |

### 阶段 B · 公开案例页（P0）

| ID | 任务 | 说明 |
| --- | --- | --- |
| CASE-SRC-B01 | H5 案例页同构 | 先要旨与本单问答，后详情、图、评价；咨询只回本店 |
| CASE-SRC-B02 | 检索字段同源 | SEO 描述 / 页顶摘要由商家确认的要旨派生，不再另写一篇 AI 摘要当信源 |

### 阶段 C · 店内类目文件夹（P1）

| ID | 任务 | 说明 |
| --- | --- | --- |
| CASE-SRC-C01 | 门店页按类目分组 | 该类目公开条数 + 案例链接；仅本店 |
| CASE-SRC-C02 | 不做独立答案 URL | 不新增「店属专题文章」。若要类目深链，只是该夹列表，不当信源正文 |

### 阶段 D · 清除不相干历史功能（P0/P1）

不迁移历史专题/跨店聚合内容。页面可 404/410 或停入口。

| ID | 清除对象 | 说明 |
| --- | --- | --- |
| CASE-SRC-D01 | 专题文章当 AI 入口 | 运营「写专题给大模型搜」、`geo_pages` 当答案文、页内通用 FAQ 工厂。`/topic/` 保持跳转或结束页即可 |
| CASE-SRC-D02 | 服务项目比店 | 目录服务页「按价格/距离/透明度挑选门店」整段拿掉。店自己的套餐仍挂在门店页 |
| CASE-SRC-D03 | 首页/城市推荐门店 | 跨店店榜，与帮商家 GEO 无关 |
| CASE-SRC-D04 | 跨店公开统计句 | 公网「全城 N 条」写进服务/专题摘要。内部分析可留，不进公开页 |
| CASE-SRC-D05 | 过审后改案例 FAQ | enrichment 改问答、运营挂专题 FAQ、案例生成器「至少 3 条」 |

### 阶段 E · 相册源头（P1，不挡 A）

| ID | 任务 | 说明 |
| --- | --- | --- |
| CASE-SRC-E01 | 完工前备注 | 引导写清：留几天、能否开走、为何不换/不连盘、旧件。没写则案例问答为空，生成器不补 |

---

## 4. 明确不做（本计划）

- 平台百科（故障灯总表、保养周期大全）  
- 跨店专题库、服务页帮人选店  
- 为旧 `geo_pages` / Feed 专题条目做数据迁移  
- 用大模型看原图写案例  

---

## 5. 验收（核心）

1. 生成页能按上网文章顺序预览；店长看见「这篇答了哪几个问题」。  
2. 问答每条能对上相册文字；无依据则 0 条；无模板凑数。  
3. 过审后 H5 与生成确认稿同构；问答在快照内，运营改不了正文问答。  
4. 门店页只出现本店案例，按类目分夹。  
5. 公网不再把专题文章、服务店榜、跨店 N= 当作检索主入口。
