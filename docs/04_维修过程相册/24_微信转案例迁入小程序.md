# 微信群转案例迁入小程序（三期）

> **生效**：2026-09-03  
> **配套**：[`14_四件套`](../01_项目总览与业务架构/14_四件套产品架构与定位.md) · [`22_微信群归档转案例目标定义.md`](./22_微信群归档转案例目标定义.md)

## 1. 目标

- 产出：**完整相册 + 面向车主单据**，不是官网草稿。  
- 入口：`packageMerchant/pages/tools/wechat-archive`  
- 官网 `/archive`：一期导流页；本能力上线后正式下线主功能。  
- 来源标签：统一 **商家上传**（不再对外标「沟通记录转化」）。

## 2. 流程

```text
粘贴群聊 → 客户端/服务端脱敏（MASK_RULES shared）
  → generateCase（复用 backend wechat-archive.service）
  → 写入新建服务相册节点 + 单据骨架
  → 门店编辑确认 → 托管/公开（同主链路）
```

## 3. 配额

沿用账户配额策略（游客/登录/白名单）；小程序内以商家登录为准，按商家账号计次。

## 4. 页面骨架

见 `packageMerchant/pages/tools/wechat-archive/`（一期导流已指向；三期接 API）。
