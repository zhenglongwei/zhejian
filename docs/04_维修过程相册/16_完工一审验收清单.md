> **日期**：2026-07-26

## 商家锁定

- [ ] 确认并完工后：商家 `save` / 案例稿修订 / AI 润色 → **409**
- [ ] 平台一审**驳回**后：商家可再编辑，再确认完工再送审
- [ ] 车主**撤回**发布后：商家仍 **409**（不可再改）

## 车主可见性

- [ ] 一审未通过：可看私密维修相册；不见案例稿 / 上网预览 /「发布到公开网站」
- [ ] 一审未通过：详情尾页或提示可见「门店案例审核中」
- [ ] 一审通过：可看案例稿；可预览脱敏并发布

## 发布与撤回

- [ ] 一审通过后发布：立即上 H5/GEO；**不**进入闸门 B 待审
- [ ] 撤回：公开下线；相册仍锁定；可再发布（新 snapshotVersion）

## 运营台

- [ ] 「相册完工合规」为唯一阻塞审入口
- [ ] 「案例公示审核（闸门 B）」不再因新发布写入待审（遗留/抽检可留）
