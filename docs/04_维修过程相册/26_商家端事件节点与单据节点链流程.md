## 1. 目标

一次服务 = 一条 **按时间排序的节点链**。节点分两类：

| 类型 | 作用 |
| --- | --- |
| **拍照节点** | 只收过程照片；**每张图下写本图说明** |
| **单据节点** | 只承载 **一份** 面向车主的单据；可引用上游照片 |

商家编辑页 = **单页竖向时间线**（`flow-stepper`）：已完成折叠只读、当前步展开内嵌编辑、未解锁不展示。禁止横向 Tab；上传 **不跳页**。

---

## 2. 标准节点链（无增项 · 7 步 · flowVersion 3）

```
接车与检测 → 检测报告 → 报价确认单 → 工单 → 施工 → 完工照 → 维修报告（含质保）
```

| sort | kind | 显示名 | nodeCategory | 需车主确认 |
| ---: | --- | --- | --- | --- |
| 0 | `intake_inspection` | 接车与检测 | photo | 商家确认本步 |
| 1 | `inspection_report` | 检测报告 | document | **是** |
| 2 | `quote_confirm` | 报价确认单 | document | **是** |
| 3 | `work_order` | 工单 | document | 否 |
| 4 | `work` | 施工 | photo | 商家确认本步 |
| 5 | `delivery_photos` | 完工照 | photo | 商家确认本步 |
| 6 | `repair_report` | 维修报告（含质保） | document | **是** |

### 渐进展示

- 仅展示：已完成（一行，可点开只读）+ 当前步（展开）。
- 解锁：上一步 `completed` 或单据 `confirmed` → 下一步 `in_progress`。
- 已完成 **不可改**；修订 = 新增同类型节点（二期；正文指纹变了才重确认）。

### 拍照文案

- 主材料 = **照片 + 本图说明**；无整段「检测说明」必填框。
- 确认本步：软提示「建议每张写一句」；未写可继续；报告空图注 =「未备注」。

## 4. 单据字段表与生成规则（真源）

> **不用大模型** 写报告正文。一期规则生成 + 商家微调。  
> 参考区间可写，公域藏精确价策略另遵价格合规文档。

### 4.1 检测报告 `inspection_report`

**够撑**：社区店「有图有话」的过程检测说明。  
**不够**：4S 全车体检 / 知车式强制清单。

| 区块 | 字段 | 来源 |
| --- | --- | --- |
| 页头 | `vehicleBrand` / `vehicleSeries` / `vehicleYear` | 相册车辆 |
| 页头 | `mileageText` | 接车图注优先，否则车辆里程字段 |
| 页头 | `chiefComplaint` | 可选；相册/商家补一句主诉 |
| 页头 | `reportDate` | 生成日 |
| 初始状态 | `intakePhotos[]`：`{ imageId, url, caption }` | stage_1 |
| 发现项 | `findings[]`：`{ imageId, url, caption, captionEmpty }` | stage_2 每图一行 |
| 未检声明 | `disclaimer` | 固定套话（见下） |
| 结论 | `conclusion` | 商家手填，可空 |

固定未检套话：

> 本次说明仅针对已拍摄部位；未拍照部位不构成全车体检结论。

**生成时机**：商家确认「接车与检测」后自动生成草稿 → 状态 `pending_confirm`。

### 4.2 报价确认单 `quote_confirm`

| 字段 | 说明 |
| --- | --- |
| `lines[]` | `{ name, note, priceHint }` **商家手填**；系统不从照片拆行 |
| `confirmCopy` | 确认文案（配件说明、费用以到店为准等） |
| `evidenceRef` | 引用检测报告 id / 发现项缩略图 |

**生成时机**：检测报告确认后解锁；**行项空草稿**，商家填写后发送确认。

### 4.3 工单 `work_order`

| 字段 | 说明 |
| --- | --- |
| `items[]` | 自已确认报价行：`{ name, note, technician?, planNote? }` |
| `sourceQuoteNodeId` | 来源报价确认节点 |

**生成时机**：报价确认单确认后 **原样带入**；商家可改技师/计划，不改已确认项目名（改项走修订）。

### 4.4 维修报告（含质保）`repair_report`

= **完工确认单**；取消独立 `warranty` 节点。

| 区块 | 字段 | 来源 |
| --- | --- | --- |
| 摘要 | `chiefComplaint` | 检测报告/主诉 |
| 已施工 | `workItems[]` | 已确认工单/报价行 |
| 验证 | `deliveryPhotos[]` | 完工照 + 图注 |
| 质保 | `warrantyPeriod` / `warrantyScope` / `warrantyExclusions` | 店规模板，可改 |
| 确认文案 | `confirmCopy` | 认可施工与质保条款 |

**生成时机**：商家确认「完工照」后自动草稿 → `pending_confirm`。

## 5. 确认与代确认

适用于：`inspection_report`、`quote_confirm`、`repair_report`、`addon_quote_confirm`。

| 状态 | 展示 |
| --- | --- |
| 待确认 | 「待车主确认」 |
| 车主已确认 | 「车主已确认」+ 时间 |
| 商家代确认 | 「商家代确认」+ 操作人 + 时间；**可选**证明图 1–3 张 |

商家在进度页操作；车主在车主端异步确认后回写解锁。确认件冻结；修订另存。
