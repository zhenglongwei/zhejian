# 案例档案下载与硬删策略（三期）

> **生效**：2026-09-03  
> **配套**：[`15_托管状态机`](../01_项目总览与业务架构/15_案例档案与托管状态机.md)

## 1. 下架 ≠ 硬删

| 动作 | 公域 | 商家私密档 | 审计 |
| --- | --- | --- | --- |
| 取消公开 | 下线 | 保留 | 留痕 |
| 取消托管 | 下线 | 小程序侧可留 | 留痕 |
| **硬删** | 立刻净空 | **删除**（二次确认） | **必须**留审计日志（谁、何时、albumId/caseId） |

## 2. 下载

- 门店可导出完整档案包（图文 URL 清单、概况、FAQ、确认件 JSON、修订历史）。  
- 不含其他门店数据；导出链路鉴权同商家相册。

## 3. 硬删建议实现

1. `POST /merchant/service-albums/:id/hard-delete`，body 含 `confirmText: 'DELETE'`  
2. 先 unpublish + unhost，再删 DB 行与可选 OSS 对象  
3. 写入 `HardDeleteAudit`（或操作日志表）

**注意**：与旧「删除不留影子副本」话术对齐时，审计日志仍保留元数据（不含内容正文），法务可再裁。
