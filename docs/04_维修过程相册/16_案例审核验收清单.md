# 案例审核收口 · 端到端验收清单

> **关联**：Phase1 §4.5 / §4.5.7 · 流程 §6–§7 · 开发计划 §7.12（CASE-REVIEW-ONCE）  
> **日期**：2026-07-27  
> **取代**：原 `16_完工一审验收清单.md`（相册完工合规作为唯一阻塞）

## 商家锁定

- [ ] 确认并完工后：商家 `save` / 案例稿修订 / AI 润色 → **409**；案例先为 `pending_desensitize`
- [ ] 脱敏结束后升为 `pending_review`（失败/需人工也进待审并标出）
- [ ] 案例审**驳回**后：商家可再编辑相册节点与案例稿，再确认完工再送审
- [ ] 案例审**通过**后：商家仍 **409**
- [ ] 车主**撤回**发布后：商家仍 **409**（不可再改）

## 车主可见性

- [ ] 案例审未通过（含脱敏中 / 待审 / 驳回）：**不可打开**服务相册详情；列表提示审核中
- [ ] 案例审通过（`review_passed`）：可看相册与案例稿；可预览脱敏并发布

## 发布与撤回

- [ ] 案例审通过后发布：立即上 H5/GEO；**不**再进人审队列
- [ ] 撤回：公开下线；相册仍锁定；可再发布（新 snapshotVersion）

## 运营台

- [ ] 「案例审核」为唯一阻塞审入口；「脱敏处理中 / 待审核」分 Tab
- [ ] 操作仅 **通过 / 驳回** + **重试脱敏**（无「要求修改」、无运营手工打码）
- [ ] 通过后状态为 `review_passed`，**不上线**；驳回后状态 `rejected` 且商家解锁、车主仍不可见
