---

## 3. 公域策略

> 车主「发布到公开网站」+ 脱敏 + 人工审核通过后，**均可基础收录**（可进 sitemap、`seo_noindex=0`），**不**以套餐作为收录 gate。

---

## 4. 商家端路径

1. 入驻审核通过 → 直接进门店选择 / 工作台（不经过试用开通）。  
2. 工作台首页店名旁：**收费**（仅主账号可点）→ 收费页。  
3. 收费页：一档，标签写「金额」，数字先空着。无支付按钮，不写「以后何时收费」。  
4. 金额下方只列四行，不写每项是什么意思：不限次使用AI分析；无限案例公示；访问数据看板；无限生成朋友圈、自媒体图文转发素材。门店页算在案例公示里，不单列。服务过程相册、车主确认是基础能力，不进收费页。打码不进收费页，也不在此向门店解释。

---

## 5. 数据迁移

- 脚本：`backend` 下 `npm run subscription:force-free`（支持 `DRY_RUN=1`）  
- 作用：全部 `merchant_subscriptions` → `plan=free`、`status=active`、清空到期与预约变更，并同步案例收录权益。
