# 商家套餐与权益

> 商家工作台收费页：四档月费对照、选档、微信支付开通。运营后台可改目录价与门店特价。

## 1. 四档对照

行是版本，列是服务内容，末列是价格。额度数字用「≤N个」。

| 版本 | 相册生成 | AI分析 | 公开托管 | 价格 |
|---|---|---|---|---|
| 尝鲜版 | 不限 | ≤3个 | ≤3个 | ¥29/月 |
| 小微店 | 不限 | ≤20个 | ≤20个 | ¥89/月 |
| 标准店 | 不限 | ≤100个 | ≤100个 | ¥249/月 |
| 规模店 | 不限 | ≤200个 | ≤200个 | ¥499/月 |

- **相册生成**：各档都不限本数；**私密托管不占额度**。
- **AI分析**：与「公开托管」**分开计**；各档上限数字相同（如尝鲜各 ≤3）。
- **价格**：目录价（分/月）；门店有特价时收费页该行显示特价。

## 2. 对象怎么装

| 对象 | 什么算一项 | 身份 | 住在项里 |
|---|---|---|---|
| 套餐目录 | 一档版本 | `planCode`（taste / micro / standard / scale） | 名称、相册不限、AI 上限、公开托管上限、目录价 |
| 门店特价 | 某店对某一档的覆盖价 | `storeId` + `planCode` | 只覆盖价格；额度仍读目录 |
| 商家订阅 | 一商家一条 | `merchantId` | 当前档、状态、本期开始日、到期日、预约降档 |
| 计费周期 | 订阅上一段有效权益窗口 | 本期 `startedAt`～`expiresAt` | 额度只在本窗口内累计 |
| 支付单 | 一次开通/续费/升档 | 支付单 id | 档位、金额、微信预下单与回调 |
| 相册周期占用 | 某本相册在**某一周期**内的一次占用 | `albumId` + 占用时刻落在该周期内 | `quotaMeta.aiAnalysisConsumedAt` / `publicHostConsumedAt`（ISO 时间） |

**有效权益档**：当前周期未到期 → 所在档；**已到期或无周期 → 无权益（额度 0，须付费开通）**。不再「未付长期白用尝鲜」。

### 2.1 新注册与全量试用

- **新注册商家**：自动写入尝鲜版，到期日 = 开通日 + 30 天（赠送，不扣款）。
- **存量统一**：上线批处理时，凡当时没有有效付费/试用周期的商家，同样写入尝鲜版 + 30 天；**只送一次**，到期后不自动再送。
- 试用与付费开通的尝鲜，权益与额度规则相同。

### 2.2 AI 分析额度（按计费周期）

- **每个计费周期独立**：周期内额度从 0 计；到期后再开通（含再买尝鲜）从新周期 `startedAt` 起重新累计。
- 一本相册在**本周期内**至少成功跑过 1 次 AI，占 **1**；本周期内可继续不限次数分析，不重复占。
- **上周期已用过的老相册不自动占本周期**；若本周期内对该本再次跑成功且本周期尚未记过占用，则占本周期 1 个。
- 满额后：本周期尚未占过 AI 的相册不能再发起分析；本周期已占过的相册仍可继续分析。
- **无有效周期（已到期）**：不能发起新的 AI 分析（须先付费开通任意档）。

### 2.3 公开托管额度（按计费周期）

- **仅公开上店页**占额；私密托管不占。
- 某本相册在**本周期内第一次**成功公开上店页占 **1**；本周期内改文案、下线再上不重复扣。
- 上周期已公开过的老相册**不自动占本周期**；本周期内再次完成「首次公开记占」才扣。
- 取消公开**不退回**本周期额度。
- 满额后：本周期尚未公开占额的相册不能再首次公开上店页。
- **无有效周期**：不能新公开上店页。

## 3. 计费与支付（D15）

- **按月预付**，不做微信自动续费；仅主账号可付。
- **升档**：付新档整月价，从付款日起重开 30 天（新周期、新额度）；不退旧档余额。
- **同档续费（未到期）**：从原到期日顺延 30 天；**不重置**本周期已用额度（`startedAt` 不变）。
- **到期后再开通同档**：新开 30 天，额度按新周期从 0 计。
- **降档**：预约到当期结束再生效，本期不退。

### 3.1 到期 / 尝鲜额满与可选档

- **已到期**：必须付费；可选**任意档**（含尝鲜）。
- **尝鲜版有效期内，AI 或公开托管任一额满**：不能再买/续尝鲜；只能**升到小微店及以上**；不升则等到期后再选任意档。
- 小微店 / 标准店 / 规模店额满时的开通规则本期仍按升档/续费既有逻辑（可升更高档或等到期）。

## 4. 工作台入口文案

店名旁（仅主账号），只显示一条，优先级：

1. 已到期 / 无有效周期 →「已到期，去开通」
2. 否则 AI 额度已满 →「AI额度已满，去升级」
3. 否则公开托管额度已满 →「托管额度已满，去升级」
4. 否则处于**赠送尝鲜试用**（有效期内且从未付过套餐费）→「尝鲜试用 · 还剩 N 天」
5. 否则到期前 3 天内 →「还剩 N 天到期，去续费」
6. 否则 → 当前有效套餐名

**入驻开通成功**：Toast「已开通尝鲜试用 30 天」（短操作反馈，不写长说明）。

## 5. 工作台收费页

- 对照表：版本 / 相册 / AI分析 / 公开托管 / 价格；可开通/续费/升级。
- 尝鲜额满时：尝鲜行不可续费；更高档可升级。
- 已到期：四档均可开通。
- 支付前勾选协议；文案短操作提示，不写需求话术。

## 6. 运营后台

1. **目录价**：改四档月费。额度与档名本期不在后台改。
2. **门店特价**：商家详情按店覆盖价；留空=目录价。

## 7. 历史档位

`free` / `index_99` / `optimize_299` 只读兼容；有有效周期时映射尝鲜权益，不可新购。无有效周期则无权益。
