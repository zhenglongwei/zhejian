# 商家套餐与权益

> 商家工作台收费页：四档月费对照、选档、微信支付开通。运营后台可改目录价与门店特价。

## 1. 四档对照

行是版本，列是服务内容，末列是价格。额度数字用「≤N个」。

| 版本 | 相册生成 | AI分析 | 公开托管 | 价格 |
|---|---|---|---|---|
| 尝鲜版 | 不限 | ≤3个 | ≤3个 | ¥29/月 |
| 小微店 | 不限 | ≤20个 | ≤20个 | ¥89/月 |
| 标准店 | 不限 | ≤100个 | ≤100个 | ¥249/月 |
| 规模店 | 不限 | ≤200个 | ≤200个 | ¥499/月 |

- **相册生成**：各档都不限本数；**私密托管不占额度**。
- **AI分析**：与「公开托管」**分开计**；各档上限数字相同（如尝鲜各 ≤3）。
- **价格**：目录价（分/月）；门店有特价时收费页该行显示特价。

## 2. 对象怎么装

| 对象 | 什么算一项 | 身份 | 住在项里 |
|---|---|---|---|
| 套餐目录 | 一档版本 | `planCode`（taste / micro / standard / scale） | 名称、相册不限、AI 上限、公开托管上限、目录价 |
| 门店特价 | 某店对某一档的覆盖价 | `storeId` + `planCode` | 只覆盖价格；额度仍读目录 |
| 商家订阅 | 一商家一条 | `merchantId` | 当前档、状态、到期日、预约降档 |
| 支付单 | 一次开通/续费/升档 | 支付单 id | 档位、金额、微信预下单与回调 |
| 相册额度痕迹 | 一本相册 | `albumId` | 是否已消耗 AI 额度、是否已消耗公开托管额度 |

**有效权益档**：付费四档且未过期 → 所购档；未付、旧码、已过期 → **尝鲜版**。

### 2.1 AI 分析额度

- 一本相册内可**不限次数**跑 AI；只要**至少成功跑过 1 次**，整本占 **1** 个 AI 额度。
- 以跑成功为准；失败或未跑不算。
- 满额后：尚未用过 AI 的相册不能再发起分析；已占过额度的相册仍可继续分析。

### 2.2 公开托管额度

- **仅公开上店页**占额；私密托管不占。
- 某本相册**第一次成功公开上店页**占 **1**；之后改文案、下线再上不重复扣。
- 取消公开**不退回**额度。
- 满额后：尚未公开占额的相册不能再首次公开上店页。

## 3. 计费与支付（D15）

- **按月预付**，不做微信自动续费；仅主账号可付。
- **升档**：付新档整月价，从付款日起重计 30 天；不退旧档余额。
- **同档续费**：从原到期日顺延 30 天。
- **降档**：预约到当期结束再生效，本期不退。

## 4. 工作台入口文案

店名旁（仅主账号），只显示一条，优先级：

1. AI 额度已满 →「AI额度已满，去升级」
2. 否则公开托管额度已满 →「托管额度已满，去升级」
3. 否则到期前 3 天内 →「还剩 N 天到期，去续费」
4. 否则 → 当前有效套餐名（未付显示「尝鲜版」）

## 5. 工作台收费页

- 对照表：版本 / 相册 / AI分析 / 公开托管 / 价格；可开通/续费/升级。
- 支付前勾选协议；文案短操作提示，不写「以后何时收费」。

## 6. 运营后台

1. **目录价**：改四档月费。额度与档名本期不在后台改。
2. **门店特价**：商家详情按店覆盖价；留空=目录价。

## 7. 历史档位

`free` / `index_99` / `optimize_299` 只读兼容，映射尝鲜权益，不可新购。
