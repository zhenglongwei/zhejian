## **2. 模块定位**

商家工作台是商家在平台上的**内容管理入口**，承担：

1. 商家极简开通（软信任，非审后放行）；
2. 门店管理；
3. 员工管理；
4. 服务项目展示与管理；
5. **服务相册创建与管理**（P0 核心）；
6. 维修案例上传与公开分发；
7. 门店主页配置与预览；
8. 数据概览（曝光、相册、透明度）。

V2.0 **删除**：订单接单、履约、标记到店、提交完工、交易评价。

## **3. 入口与权限**

### **3.1 入口**

自己打开并选择（或已记住）**商家** → 工作台。未开通展示「开通商家账号」一键开通；开通后立刻进入工作台。车主页可「切换为商家」。认证与门店资料为可选完善项。工作台可「切换为车主」。

### **3.2 权限矩阵**

| 功能 | 主账号 | 门店管理员 | 员工 |
| --- | --- | --- | --- |
| 查看工作台首页 | 是 | 是 | 是 |
| 门店/入驻资料修改 | 是 | 部分 | 否 |
| 员工管理 | 是 | 可选 | 否 |
| 服务方案创建/上下架 | 是 | 是 | 否/可选 |
| 创建/编辑服务相册 | 是 | 是 | 是 |

## **4. 四格与工作台首页**

> **2026-10-11** 起，本节取代旧「单页工具台 + 三格 Dock」。

底栏四格：

| 格 | 内容 |
| --- | --- |
| 工作台 | 头图与「新建服务相册」、进行中 / 待确认 / 本月案例、正在服务的相册。待确认只表示报价还没确认 |
| 服务相册 | 相册列表。筛选项：全部、进行中、待确认、已完成。还没交车、也还没等车主确认交车的卡片可删除，确认后从商家和车主两侧一起消失；已交车的、以及正在等车主确认交车的，不能删。交车之后，这一本上的评价出现在该相册的提醒里 |
| AI 助手 | 试用页。只列进行中相册里已经生成的意见：接车意见、尚未采纳的检查建议、给店员的核对结果。没有就不编条数，也不做自由提问。报价还没发给车主时，主按钮把这条意见写成报价单的一行，金额留空。已经发给车主或已确认的，只能打开那一步查看。用过后决定是否保留 |
| 门店 | 店名一行只放编辑；点店名换店；点头像弹出菜单，菜单里切换为车主。编辑按钮和菜单「基础资料」进同一页。其下为资料完善度、基础资料、擅长服务、资质证明、账号管理。服务方案放在擅长服务里。底部只保留公开案例、本月被查看。不出现咨询数字，不写推荐概率的具体数字。补资料的说明可以写「能提高被 AI 推荐的概率」 |

未开通、未登录的门槛仍在进入工作台时出现。

## **7. 服务相册（摘要）**

- 商家为线下维修主动创建 **服务相册**（不依赖平台订单）；  
- Phase 1：**六阶段留档** + 配件录入 + 可选邀请车主查看；**不要求**配件车主确认；  
- 完工后车主可 **授权公开**（脱敏 + 审核）；  
- 详见 `04_服务相册创建与管理.md`、`04/00_Phase1_服务相册产品口径.md`。

## **8. 门店资料**

门店页进入资料编辑。执照和维修资质各有一个开关，打开才出现在网站门店页，关掉即从网站撤下。小程序预览页不写审核结论，也不列案例。

主账号在门店页点店名进入门店列表，可切换或注册新门店。只有一家店时也能进。点头像弹出菜单，切换为车主放在这个菜单里，不放在店名这一行。

评价不进工作台待办列表。交车之后，评价写在对应相册上。不计算门店平均分，店页不展示评分。待补留证和回访留在对应相册上。

服务相册列表里，档案已托管且网站可打开时，卡片可「打开网站」（小程序内网页）。

网站上的门店展示页仍列出本店公开档案。分享内容须为公开/脱敏信息。

## **9. 异常与边界**

**未认证 / 资料基础**：可创建服务相册、可托管；公开展示带身份标签；工作台引导补认证与门头等加分项。  
**已冻结 / 已关闭**：按运营处置限制公开面；关闭后不可继续以该主体经营。

---

## **10. P0 验收标准**

1. 商家一键开通可进入工作台，支持门店切换；
2. 可创建服务项目并提交上线审核；
3. 可新建 **服务相册** 并完成六阶段留档（Phase 1 无配件阻断）；  
4. 档案可邀请车主查看；车主可授权公开；  
5. ~~独立历史案例上传~~（Phase 1 已并入档案）；  
6. 工作台**无**咨询线索入口；
7. 可设置门店信息并预览门店资料（小程序该页不含案例列表）；
8. 可分享服务、案例和门店内容；
9. 关键操作有日志。
