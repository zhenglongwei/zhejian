# **《商家开通与软信任》**

> **当前版本：V2.1**（2026-09-20 · 软信任）  
> **废止**：入驻人工审核作为工作台/生产门禁；证件/门头/工位等作为开通强制项。

---

## **1. 文档信息**

| 项目 | 内容 |
| --- | --- |
| 文档名称 | 商家开通与软信任（原「商家入驻」） |
| 当前版本 | **V2.1** |
| 适用端 | 微信小程序商家工作台 |
| 核心目标 | 极简开通即可生产案例；认证与资料完整度用公开展示标签软性引导 |

**不做**：派单、在线收款、交易佣金；**暂不**开放个人注册为案例生产者（入口可预留灰态）。

---

## **2. 目标**

1. 微信登录后可一键开通**商家账号**，立刻生产相册/托管。  
2. 案例库与公开案例**如实**展示：账号类型、是否认证、资料完整度。  
3. **认证** = 上传营业执照 + 法人身份证等并通过必要自动校验（非人工放行干活）。  
4. 门头/工位/技师/授权等为**加分项**，推荐非强制。  
5. 运营以抽查、摘认证标、冻结公开为主，不以「驳回入驻」挡生产。

---

## **3. 开通流程**

```text
自己打开 → 选「商家」（或已记住商家身份）
→ 未开通：工作台内一键开通商家账号（创建 Merchant + 默认 Store）
→ 立刻进入工作台，可建相册 / 私密或公开托管（公开仍须过隐私规则）
→ （可选）完善认证与门店资料 → 提升公开展示标签
车主页「切换为商家」走同一条开通。
```

开通时**不要求**填写执照、门头、工位、资质、擅长项。店名可用占位（如「我的门店」），后续可改。

个人交档入口可展示说明，**本期不可注册为生产者**。

---

## **4. 公开身份标签**

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 账号类型 | 商家 / 个人 | 现阶段可生产的仅商家 |
| 认证状态 | 未认证 / 认证中 / 已认证 / 校验未通过 | 已认证 = 证件已交且自动校验通过 |
| 资料完整度 | 基础 / 较全 / 完善 | 由地址、坐标、营业时间、门头/工位图、技师等加分项计分 |

**禁止**写成「已审核」「平台担保真实」。标签仅描述账号资料状态。

---

## **5. 认证（可选，公开前必过）**

| 项 | 要求 |
| --- | --- |
| 营业执照照片 | 认证必交；识别法人姓名与统一社会信用代码 |
| 法人身份证人像面 | 认证必交；识别姓名 |
| 法人身份证国徽面 | 认证必交 |
| 法人一致 | 执照识别出的法人，须与身份证人像面姓名一致（以识别结果为准，不以手填框为准） |
| 执照不重复 | 全平台同一信用代码只能开一家店；已被占用则拦住 |

**提交时校验顺序**（先拦占用，再动身份证识别）：

1. 执照、身份证人像面、国徽面是否都已上传
2. 识别营业执照（主体名称、法人、信用代码）
3. 信用代码是否已被其他账号占用；占用则立刻拦住，**不再识别身份证**
4. 识别法人身份证正反面
5. 执照法人与身份证人像面姓名是否一致

识别失败、执照已被占用或姓名对不上 → 认证不通过。未认证**不挡**建相册；**挡**门店及相关内容对外公开。

开通后按步引导补认证与基础资料；中途退出后，下次用商家身份打开再领回没填完的一步。可先去干活。

---

## **6. 加分资料（推荐）**

门店名称、地址、地图坐标、营业时间、电话、门头/工位实拍、简介、擅长品牌/项目、技师公示卡、设备标签、品牌授权（含有效期）、主体与维修资质等，开通后都可改。**没有审核门禁**，也没有只读基本资料。

保存后，**仅当认证已过且基础资料已齐**，网站店页才对访客开放。缺一项则店页、该店公开案例、该店服务展示、搜索与收录一并对外下线。本店仍可预览与补资料。补齐后自动恢复，不再审门店。已公开托管的档案**不改托管记录**；商家端标签改为「已托管·网站未展示」，访客打不开。补齐后自动改回「已托管·公开」。点相册「托管到案例站」：资料不齐则说明缺什么并引导去补，允许先仅私密；已公开托管却因门店不再符合公示条件而下线，则说明原因并引导去处理。不挡私密托管。

基础资料齐：真实店名（不能是「我的门店」）、地址、电话、营业时间、介绍、门头、工位、接待区。擅长、技师、维修资质仍是加分。

不做第二步「托管门店」。案例仍要过隐私规则后才能作为案例页；但门店未达公开条件时，已过审案例也对访客下线。

| 内容 | 网站店页 |
| --- | --- |
| 店名、地址、电话、营业时间、简介、环境图、擅长、技师称呼与头像、品牌授权 | 达公开条件后出现 |
| 营业执照、信用代码、主体名称、维修资质 | 商家勾选「在网站展示」后才出现；文案写「门店自行公示」。还没保存过这个开关的旧资料，仍按原先已在店页上的方式展示，直到商家改一次 |
| 法人身份证、技师证件照片 | **不**上网站 |
| 店名仍是「我的门店」或为空，或认证/基础资料未齐 | 本店可预览；访客打不开店页；不进搜索；该店公开内容一并下线 |

虚假信息走举报与事后处置。运营可抽查、摘认证标、冻结公开面，不挡保存。

---

## **7. 员工管理**

开通后主账号可邀请员工。权限以相册/案例/门店资料为主；**无**咨询线索权限（工作台不下发线索）。

---

## **8. 运营与合规**

- 运营可抽查、**撤销认证标**、冻结/关闭门店公开面。  
- 撤销认证或冻结**不**默认收回工作台生产能力（除非账号关闭）。  
- 对外提示：资料由门店自行维护；平台不背书案例真实性。

---

## **9. P0 验收**

1. 一键开通后可立刻建相册并托管。  
2. 未认证可干活；店页与该店公开案例不对访客开放。  
3. 信用代码未被占用，且执照法人与身份证姓名一致 → 「已认证」。  
4. 认证过且基础资料齐后，店页与相关公开内容自动恢复。  
5. 运营摘标后公开展示同步；工作台仍可用。
