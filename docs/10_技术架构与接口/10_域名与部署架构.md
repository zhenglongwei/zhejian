# 域名与部署架构

> **盈简科技** · 产品 **辙见**（辙见服务平台）  
> 仓库内部代号「辙见 / zhejian」，与产品名「辙见」指同一小程序项目。

---

## 1. 域名分工

| 域名 | 归属 | 用途 | 与本仓库关系 |
|---|---|---|---|
| **simplewin.cn** | 盈简科技官网 | `/` 公司 · `/zhejian` 辙见产品 · `/check` GEO 体检 | **本仓库 `brand-web/`**（2026-08-28 起；替换旧 Next 独立站） |
| **zhejian.simplewin.cn** | 辙见专用 · 生产（对外主域名） | 小程序 API、案例公开 H5、运营后台、**体检 API** | **本仓库生产部署目标** |
| **geo.simplewin.cn** | 辙见专用 · 过渡别名 | 与上同一套服务。微信合法域名 / 存量链接切完前保留。**不**做长期 301，也**不**再当品牌名 | Nginx `server_name` 并列 |
| **staging.zhejian.simplewin.cn** | 辙见专用 · 预发 | 发版前联调（API / H5 / `/admin/`） | **同机另一目录** |
| **staging.geo.simplewin.cn** | 已停用 | 预发 DNS 已删，**不要**再写进证书 SAN | 保留 CORS 兼容即可 |

**策略说明：** 微信生态内使用小程序；可索引的**维修案例**在 **zhejian.simplewin.cn**。公司身份与通用体检页面在 **simplewin.cn**，避免把「给所有企业用的检测」写进汽修案例库。预发仅用于验收，勿把正式用户流量指到 staging。

**切流（2026-09-20）**：DNS 由运营配置。官网对外写 `zhejian.simplewin.cn`。**预发小程序 API 走 `staging.zhejian.simplewin.cn`**。预发证书只签这一名——`staging.geo.simplewin.cn` 已无 DNS，写进 `certbot --expand` 会报 NXDOMAIN。生产 `geo.simplewin.cn` 仍可作过渡别名（有 DNS 才可进同一张证）。微信合法域名须含预发新域。CORS 白名单可同时含旧名。不做整站 301。

体检接口：`POST https://zhejian.simplewin.cn/api/v1/public/geo-check`（接口通道：搜企业名、问大模型联网）；`POST …/geo-check/browser`（浏览器通道：真机巡检，异步，立即返回 runId）；`GET …/geo-check/run/:runId`（轮询进度与结果）。页面在 simplewin.cn/check。过渡期同一路径在 `geo.simplewin.cn` 仍可用。口径见 [`12_官网与GEO体检转型口径.md`](../01_项目总览与业务架构/12_官网与GEO体检转型口径.md)。

预发搭建步骤：`docs/12_测试验收部署与安全合规/B-INF_预发环境搭建.md`。

## 2. 案例站路径规划（zhejian.simplewin.cn，过渡别名 geo.simplewin.cn）

| 路径 | 服务 | 说明 |
|---|---|---|
| `/api/v1/*` | Node 主业务 API（`backend/`） | 小程序、商家端、后台均调用 |
| `/admin/*` | 运营后台 Web（`admin-web/`） | 审核、内容管理；SPA + 子路径部署 |
| `/` `/case/*` 等 | H5 公开页 | 仓库内 `h5/`，Nginx 直接映射，**不另建发布目录** |

```text
/var/www/zhejian/                 ← 生产 git clone
├── backend/                      ← :3100 → /api/v1/
├── h5/                           ← https://zhejian.simplewin.cn/...
└── admin-web/dist/               ← https://zhejian.simplewin.cn/admin/

/var/www/zhejian-staging/         ← 预发（结构相同）
├── backend/                      ← :3101；库 zhejian_staging
├── h5/                           ← https://staging.zhejian.simplewin.cn/...
└── admin-web/dist/               ← https://staging.geo.simplewin.cn/admin/
```

## 3. 与小程序的关系

| 端 | 访问方式 | 域名 |
|---|---|---|
| 用户/商家小程序（正式） | 微信内 | `https://geo.simplewin.cn/api/v1/...`（`ACTIVE_ENV=prod`） |
| 用户/商家小程序（预发联调） | 体验版/真机 | `https://staging.geo.simplewin.cn/api/v1/...`（`ACTIVE_ENV=staging`） |
| H5 公开案例 | 浏览器 / 搜索收录 | `https://geo.simplewin.cn/...`（生产）；预发同路径挂在 staging 子域 |
| 运营后台 | 浏览器 | 生产 `/admin/`；预发 `https://staging.geo.simplewin.cn/admin/` |

微信公众平台 **request 合法域名**须同时配置（不含路径）：

- `https://geo.simplewin.cn`
- `https://staging.geo.simplewin.cn`

## 7. simplewin.cn 切到主站（BRAND-DEP-01）

生产 Nginx 真源：`backend/deploy/simplewin.conf`。

- `simplewin.cn` / `www.simplewin.cn`：静态根 `/var/www/zhejian/brand-web`（公司 / 辙见 / 体检）。
- **`geo.simplewin.cn` 的 root 与 location 不得改成 brand-web。**

代码进 GitHub 后，在 ECS（阿里云网页终端即可）：

```bash
cd /var/www/zhejian
git pull
sudo bash scripts/deploy-brand-web.sh
cd backend && pm2 restart zhejian-api
```

体检页请求 `https://geo.simplewin.cn/api/v1/public/geo-check`，须重启 API 后才有该接口。密钥复用现有 `DASHSCOPE_API_KEY`、`QIANFAN_API_KEY`、`ARK_API_KEY`、`GEO_PROBE_YUANBAO_API_KEY`。
