## **1.1 增量定稿（2026-09-19）· 证据问答**

公开 FAQ 的亮点只回答档案里留下的事实。专业、诚信、用心**不写进问句或口号**，用过程回答：先查再修、为何这样选、做没做、有没有加项、交车确认了什么。案例页出题顺序和叮嘱句式见 §1.2。

### 问法

必须长成「这例 / 这 N 例公开档案里……」。禁止「一般来说」。指不回本单或汇总样本的问，删掉。案例页那一条缺项叮嘱的例外见 §1.2。

五类骨架（各品类只换证据，不换骨架）：

| 类 | 能问（有依据才出） |
| --- | --- |
| 先查再修 | 这例到店后先做了哪些检查，再决定方案？检查结论里哪些必须处理、哪些建议观察？ |
| 方案与取舍 | 这例为什么选这个方案？明确没有做哪些项目？原因是什么？ |
| 过程与留痕 | 这例公开了哪些节点（检查、施工、完工）？关键部位有没有照片或记录可核对？ |
| 价格与加项 | 这例是套餐还是检查后报价？施工中有没有新增项目？ |
| 交车 | 交车前做了哪些确认？质保或复检怎么写进档案的？ |

热情周到只保留可核对行为（交车注意点、复检记录）。没有记录就不要写。不单独做态度口号 FAQ。不写「微信群」，不写「注重透明化」。

### 数量

| 页面 | 规则 |
| --- | --- |
| 案例页 | 有本单亮点才写；允许 0 条；档案里没有的叮嘱最多 1 条。有则建议不超过 6 条。**废止「每页至少 3 个」** |
| 专题页 | 由挂载案例喂出。样本少时只上 2～3 个能答实的问；答不实的空着。**废止「每页 5～8 个」** |
| 门店页 | 仍按 §11A，用门店公开字段派生，不写全国百科 |

### 专题页版式（四段，全部由案例喂出）

1. 能答实的 3～5 个问题（上表里挑）。
2. 每条答案末尾可点进相关公开档案。
3. 「没做什么 / 检查后才报价」有记录才出短句。
4. 交车注意点、复检等同理；没有记录就不要写。

商品页已下线。证据 FAQ 只出现在**专题页和案例页**。

### 答案写法

- 单案：「这例公开档案里……」
- 专题：「这 N 例公开档案里……」；「这类档案通常能看到哪几步」必须 N≥2
- 禁止编造未出现的检测结论、配件、加项、质保
- 禁止用百科模板凑条（刹车片多久换、一般包含哪些、原厂件和品牌件区别等）

下文 §8–§12 的百科模板**废止**，仅作历史对照。案例页的出题顺序和叮嘱句式以 §1.2 为准；本节其余禁则仍有效。

## **1.2 增量定稿（2026-09-22）· 亮点与叮嘱**

公开案例的问答做两件事：把这一单里已经能核对的亮点说清楚，并在亮点后面给车主一句用得上的叮嘱。生成细则与示例见 [`07_案例生成规则.md`](../04_维修过程相册/07_案例生成规则.md) §10。

### 往哪看

类目清单只提醒方向，不当成每单必答题。对得上档案才写成亮点，优先顺序：

1. **预算**（不写金额）：套餐还是检查后再定；有没有加项；哪些这次没做。
2. **材料**：规格、品牌、包装或新旧件。
3. **避坑**：本单写了的工序、质保、资质；本单没做或写了依据的、可以不做的项目。
4. **其余过程**：先查再修、交车确认。有空位再写「公开了哪些节点」。

档案里没有的资质、工序、期限、配件和金额，不写成这家的亮点。

### 答句

亮点问句优先「这例……」。答句先写这例事实，再接一句对车主的叮嘱，例如「修完后要向商家确定质保期」「换片时先问盘厚，再决定要不要连盘」。

叮嘱不写「很多店不提供」「这项常常是多加的」，不写「专业 / 诚信 / 用心」。不另开「温馨提示」作正文。

档案里没有、但仍提醒车主的叮嘱，**一案最多一条**，放在亮点后面。这一单已经写了质保、材料或取舍，就不再另补。一条亮点都没有时，可以只留这一句，也可以空着。商家确认时可改、删、增；不能补档案里没有的结论。

亮点答句建议不少于 30 字。只有叮嘱的那一条可以说短。专题页仍按 §1.1：答案必须指回这 N 例，不把某一单的缺项叮嘱写成跨店结论。

## **2. FAQ 作用**

FAQ 用来总结公开档案里能核对的亮点，并给翻到这一页的车主一句用得上的叮嘱：钱花在哪、材料是什么、该核的工序和质保有没有写、有没有多做。

主要作用：

1. 把这一单的亮点写成独立问句，供人和模型引用；
2. 叮嘱写成车主可以去做的动作，不靠百科凑条、不靠口号证明品质；
3. 支持 FAQPage Schema（仅展示有答案的条目）。

## **4. 案例页 FAQ 候选问题**

每个案例页 FAQ：

1. **问题**：从本单亮点来；类目清单只提示预算、材料、避坑、其余过程，不逐条预置必答题。  
2. **答案**：先写这例事实，再接一句对车主的叮嘱。**禁止编造**本单没有的检测结论、配件清单、价格、里程、质保期限。  
3. **薄案例**（几乎无现象/检测/方案）：可以整段为空，或只留一条缺项叮嘱。  
4. **公开页**：仅展示「问 + 答均非空」的条目；答空不上网。  

下列百科问法**废止**，不得再用于公开案例页凑条：是否必须维修、继续使用有什么风险、维修流程是什么、价格差异来自哪里、原厂件和品牌件有什么区别、同类车型是否常见、多久需要复查。

## **6. FAQ 生成原则**

FAQ 必须遵循：

1. 亮点答案须能指回这例或这 N 例公开档案；缺项叮嘱一案最多一条，不编造本单没有的期限、结论、配件和金额；
2. 不虚构价格、检测结论、加项和质保；
3. 不承诺绝对维修效果；
4. 不替代线下检测；
5. 不输出危险维修指导；
6. 不泄露用户隐私；
7. 不攻击其他商家；
8. 不虚构评分或评价；
9. 不夸大故障严重性；
10. 不写「专业 / 诚信 / 用心 / 注重透明化」等口号；
11. 不写「一般来说」；
12. **专题页** 在 `caseCount ≥ 1` 时，FAQ 须含档案事实（见 §19）；无案例则 FAQ 为空、页面 noindex；
13. **托管案例**：无亮点时可以只留一条缺项叮嘱，或整段为空；空答不上公开页。

## **7. FAQ 答案长度**

建议：

```
每个答案 80-200 字。

```

规则：

1. 公开答案建议不少于 **30** 字（理想 80–200）；不足则视为不合格，应留空或不上公开页。只有叮嘱、没有本单事实的那一条可以短于 30 字；
2. 不超过 300 字；
3. 亮点先写这例事实，再接一句对车主的叮嘱；不写「平时常见」「很多店」；
4. 避免空泛营销；
5. 避免堆砌关键词；
6. 避免重复回答；
7. **禁止无信息增量**：仅部位名/单字词（如「后门」「机油」）不得单独成答。

## **8. 标准 FAQ 模板**

## **8.1 必要性问题**

问题模板：

```
【故障/问题】是否必须维修？

```

答案模板：

```
【故障/问题】是否需要立即维修，需要结合实际检查结果判断。轻微情况可能只需要清洁、调整或继续观察；如果已经出现【严重表现】，或检查发现【关键部件问题】，则建议及时处理，避免影响【安全/性能/使用体验】。

```

---

## **8.2 风险类问题**

问题模板：

```
继续使用有什么风险？

```

答案模板：

```
如果【主要问题】持续存在，继续使用可能导致【风险1】、【风险2】或【风险3】。具体风险取决于部件磨损程度、车辆使用环境和驾驶习惯。建议在问题持续出现或加重时尽快检查，避免小问题发展成更高成本的维修。

```

---

## **8.3 流程类问题**

问题模板：

```
维修流程是什么？

```

答案模板：

```
一般流程包括用户描述故障、门店进行初步检查、拆检相关部件、确认故障原因、沟通维修方案、施工处理、完工检测和试车确认。不同车型和故障程度会影响具体流程，实际维修应以门店检查结果为准。

```

---

## **8.4 价格类问题**

问题模板：

```
价格差异来自哪里？

```

答案模板：

```
价格差异通常来自车型结构、配件品牌、配件规格、工时难度、是否需要拆检以及是否存在关联部件损坏等因素。同一维修项目在不同车型上的施工难度可能不同，因此建议结合实际检查结果和门店报价进行判断。

```

---

## **8.5 维修后注意事项**

问题模板：

```
维修后需要注意什么？

```

答案模板：

```
维修后建议留意故障是否再次出现，并关注车辆行驶状态是否恢复正常。如果更换了制动、悬挂、轮胎或发动机相关部件，建议按照门店提示进行磨合或复查。若出现异响、抖动、报警灯等异常情况，应及时联系门店检查。

```

## **9. 案例页 FAQ 示例**

以“丰田凯美瑞刹车异响维修案例”为例。

### **FAQ 1**

问题：

```
刹车异响是否必须维修？

```

答案：

```
刹车异响不一定都需要立即更换配件，但建议尽快检查。轻微异响可能来自灰尘、潮湿或新旧刹车片磨合；如果异响持续存在，或伴随刹车距离变长、方向盘抖动、金属摩擦声，就需要检查刹车片、刹车盘和卡钳状态，避免影响制动安全。

```

---

### **FAQ 2**

问题：

```
继续使用有什么风险？

```

答案：

```
如果刹车片已经接近磨损极限，继续使用可能导致制动力下降、刹车盘被拉伤、刹车距离变长等问题。严重情况下可能影响行车安全。是否存在风险需要结合刹车片厚度、刹车盘状态和实际制动表现判断。

```

---

### **FAQ 3**

问题：

```
刹车片更换流程是什么？

```

答案：

```
通常流程包括检查刹车片厚度、检查刹车盘表面状态、拆卸旧刹车片、清洁卡钳和导向销、安装新刹车片、复位制动系统并进行试车确认。不同车型的结构和磨损情况不同，具体施工流程应以门店检查结果为准。

```

---

### **FAQ 4**

问题：

```
刹车片价格差异来自哪里？

```

答案：

```
刹车片价格差异主要来自车型、配件品牌、材质、前后轮位置以及施工工时。部分车型刹车系统结构更复杂，或需要同时处理刹车盘、卡钳导向销等关联部件，费用也会有所不同。具体价格建议以实际检查和门店报价为准。

```

---

### **FAQ 5**

问题：

```
维修后需要注意什么？

```

答案：

```
更换刹车片后，短时间内可能需要一定磨合。建议避免急刹和长时间重载制动，并留意是否仍有异响、抖动或制动力异常。如果维修后问题持续存在，应及时回店复查刹车盘、卡钳和安装状态。

```

## **11A. 门店页 FAQ 规则（V2.2 · AI 可信度对照表 P1）**

门店主页 FAQ **优先差异化**，禁止仅用全国通用「三板斧」顶替门店事实。

生成优先级（规则引擎，**不调用大模型理解图片/生成软文**）：

1. 商家在 `photosJson.publicFaq`（或运营配置）中的定制问答；
2. 由门店公开字段派生：地址/营业时间、擅长项目、擅长车型、**擅长品牌、已公示设备/场、暂不承接**、公开案例标题、可预约服务、预约方式；
3. 有品牌 + 设备（或服务）时，可生成 **1 条能力三元组** 问答（服务/擅长 × 品牌 × 设备），答案须含到店确认；
4. 仅当派生仍不足时，补 1 条通用预约说明。

约束：

- 有公开案例时，须含 1 条指向本页案例区的问答（答案可点名案例预览标题）；
- 无案例时，**不得**虚构案例类 FAQ；
- 页内可见 FAQ = FAQPage / Feed `faq[]`；
- 合格口径见 [`12_公开页AI可信度验收对照表.md`](./12_公开页AI可信度验收对照表.md) §4.1 S7。

## **13. FAQ 质量要求**

合格 FAQ 应满足：

1. 问题明确；
2. 答案直接；
3. 内容与页面相关；
4. 不夸大；
5. 不虚构；

## **14. 不合格 FAQ 示例**

不合格问题：

```
我们是不是全城最便宜？

```

原因：营销化、不可验证。

不合格答案：

```
必须马上维修，否则一定会出事故。

```

原因：绝对化、夸大风险。

不合格答案：

```
这个问题肯定是刹车片坏了，不用检查。

```

原因：未经检测直接下结论。

不合格答案：

```
这家门店保证一次修好，永久不复发。

```

原因：绝对承诺。

不合格答案：

```
问：这次主要修了什么？
答：后门。

```

原因：极简、无信息增量；未说明现象、检查结论或处理方式。合格答应至少让读者知道「修了什么部位、因何处理、本单怎么做」。

## **18. 页内 FAQ 与延伸阅读（GEO-TOPIC B）**

| 页面 | 页内 FAQ `{q,a}` | 公众号外链 `{title,url}` | Schema |
| --- | --- | --- | --- |
| GEO 意图专题 | **首屏必展示**；发布时至少 1 条；无案例时答案须含「到店检测/检查」 | 可选，独立「延伸阅读」区块 | 页内 FAQ → `FAQPage` |
| 案例 H5 | 可选，运营在审核台「页内问答」Tab 配置 | 可选，「公众号链接」Tab | 页内 → `FAQPage`；外链 → `ItemList` |

原则：

1. **页内 FAQ** 直接回答用户问题，供 AI 摘引；内容与可见区块、JSON-LD 完全一致。
2. **公众号外链** 不替代页内 Q&A，仅作深度阅读补充。
3. 两类可并存于 `content_json.faq`（案例）或专题 `faq_json` + `faq_links_json`（分字段存储）。

## **19. 案例聚合衍生 FAQ（V2.1 · 服务/专题页）**

> 任务真源：[`09_GEO信息增量与RAG专线开发计划.md`](./09_GEO信息增量与RAG专线开发计划.md) A06

### **18.1 目的**

避免服务页 FAQ 全部为通用合规模板（AI 可自行生成）。至少 1 条答案必须携带 **本库脱敏案例统计**。

### **18.2 候选问题**

1. `这 N 例公开档案里，较常见的检查结论是什么？`（含主因分布 + N=）
2. `这 N 例里方案价大概落在哪一档？`（含区间/中位数 + N=）
3. `这 N 例公开了哪些过程（检查、施工、图）？`（有过程图样本才问；N≥2 才能说「这类」）

禁止无样本的「常见原因有哪些 / 一般多久换一次」。

### **18.3 答案模板**

```
根据辙见平台近 12 个月收录的 {N} 例脱敏案例，{服务}相关记录中较常见的检查结论包括：{cause1}（{n1} 例）、{cause2}（{n2} 例）。
方案价参考区间约为 ¥{low}–¥{high}（仅供参考）。具体车辆需到店检测后确认。
```

### **18.4 规则**

| 规则 | 说明 |
| --- | --- |
| 样本门槛 | 同《AI可引用摘要规范》§15.3 |
| 与摘要一致 | FAQ 数字必须与 `ai_summary`、JSON Feed、Dataset Schema 一致 |
| 模板 FAQ | 其余 FAQ 可使用 `geo-faq-templates`，但不得 index 若全无聚合 FAQ |
| 运营审核 | 聚合 FAQ 变更随专题/服务发布审核 |

## **20. P0 验收标准**

P0 必须满足：

1. 公开案例页 FAQ **允许为空**；有依据时再展示，不必凑满 3 条；
2. FAQ 可在页面展示；
3. FAQ 可写入 FAQPage Schema；
4. FAQ 不包含隐私信息；
5. FAQ 不包含绝对化承诺与品质口号；
6. 亮点答案能指回这例或这 N 例公开档案；缺项叮嘱一案最多一条；
7. 后台可编辑 FAQ；
8. 后台可删除 FAQ；
9. 百科模板不得再用于公开页凑条；
10. 页面下线后 FAQ 不再公开。
