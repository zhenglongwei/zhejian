# 视频号「畅想未来生活」内容规划

> 状态：共识中（2026-08-14）  
> 主体：杭州盈简科技有限公司（趋势向内容号，**不绑定辙见/汽修产品**）

## 1. 定位

| 项 | 口径 |
| --- | --- |
| 号名 | **畅想未来生活** |
| 主任务 | 最大限度触及**普通人**，植入「未来 AI agent 无处不在」 |

## 2. 片型与制作

| 项 | 共识 |
| --- | --- |
| 主片型 | **第一人称 POV**，全程**不出人**；只拍环境、设备、界面、车内/家居等 |
| 声音 | AI 旁白/对白完成「人在问、agent 在答」 |
| 时长 | 约 30～60 秒 |
| 节奏 | **周更 1 条**，重质不重量 |
| 换气 | 绝大多数 POV；偶发一条「纯环境蒙太奇 + 旁白」（仍不出人） |
| 生成 | 画面与声音均以 AI 生成为主，人工负责脚本、选片、拼接、字幕与终审 |

### 2.1 标准节拍（可套用）

1. POV 看见异常或需求（灯、提示、空冰箱、日程冲突…）  
2. 开口问 AI（画外音）  
3. AI：解释 → 判断轻重 → 给方案 → 必要时荐附近服务/下一步  
4. 人同意（一句话即可）  
5. 环境给出结果（车起步、灯调好、订单确认、家电启动…）  
6. 片尾：关注引导 + 下期预告  

范例（出行/车，仅占系列一块）：故障灯亮 → 问含义 → AI 判严重度与方案 → 荐附近合适店 → 同意 → 车子出发。

### 2.2 成本参考（周更 1、重质）

| 档位 | 单条全成本（含废片） | 说明 |
| --- | --- | --- |
| 试水 | 约 50～200 元 | 能发，质感易飘 |
| **建议起步** | **约 200～600 元** | 多镜返工 + 配音字幕，更贴「重质」 |
| 冲刺 | 约 800～2000+ 元 | 观感更好，早期试错偏贵 |

另计工具会员（常见几十～数百元/月）。成片贵在**废片与返工**，不在单次点生成。  
POV 不出人通常比数字人出镜更省、更稳。

> 预算档位若未另定，执行时默认按「建议起步」试前 4～8 条，再复盘。

## 3. 场景池（前 8 条配比原则）

生活面铺开，避免做成修车专栏：

- 家居  
- 出行（**含至多 1～2 条车相关**即可）  
- 购物决策  
- 健康或饮食  
- 工作 / 日程助手  

---

## 4. 前 8 条选题草案

| # | 标题意向 | 场景 | 一句话情节 |
| --- | --- | --- | --- |
| 1 | 冰箱空了，晚饭谁定？ | 家居/饮食 | POV 看空格层 → 问 AI 今晚吃什么 → 按库存与口味出菜单 → 下单缺的食材 → 门锁/配送进度在屏上跳 |
| 2 | 故障灯亮了以后 | 出行/车 | 仪表故障灯 → 问含义与严重度 → 荐方案与附近店 → 同意 → 车子上路（范例正式条） |
| 3 | 会议室撞期了 | 工作 | 日历红块冲突 → AI 改期并通知相关人 → 屏幕确认「已改到周四」 |
| 4 | 这件外套该不该买 | 购物 | POV 商品页与评价乱飞 → 问是否适合自己场景 → AI 对比要点 → 加入购物车或关掉页面 |
| 5 | 夜里咳嗽声 | 健康/家居 | 卧室暗光 + 声音提示 → AI 问症状时长 → 建议观察或约号 → 手机弹出预约成功（不出病人正脸） |
| 6 | 下雨天，伞在哪 | 家居/出门 | 门口湿痕与天气预报 → AI 提醒带伞并说伞在玄关左侧 → POV 伸手拿起伞出门 |
| 7 | 快递到了没人 | 家居 | 门口柜/门锁提示 → AI 核验取件码 → 柜门打开 → 包裹入画 |
| 8 | （换气）城市里的安静助手 | 蒙太奇 | 不出对白长段：窗、灯、导航、灶台提示轮切 + 一句旁白「它们开始替你记事」；片尾下期预告回情景剧 |

每条片尾固定：**关注畅想未来生活** + **下期预告一句**。

## 5. 制作清单（每条）

- [ ] 30～60 秒脚本（问句 / AI 答要点 / 同意句 / 结果镜头）  
- [ ] 分镜表（每镜环境主体，禁止出现可辨人脸）  
- [ ] AI 出片（多段短镜）→ 人工拣镜拼接  
- [ ] AI 旁白/对白 + 字幕（含片尾关注与预告）  
- [ ] 终审：无真人出镜、无辙见硬广、无违规医疗/金融承诺
