## 0. 公司与产品定调（背景）

| 项 | 口径 |
| --- | --- |
| 公司 | 杭州盈简科技有限公司 |
| 公司业务定位 | 帮助合作伙伴打造面向 GEO 的独特数字资产 |
| 辙见 | 公司在汽修行业的落地项目 |
| 做法 | 以小程序为工具，沉淀严谨维修过程与真实信息，生成高可信度案例（自动化案例生成器）；案例收录于辙见公网，商户也可分发至知乎/头条/小红书等 |
| 不做 | 传统「靠发软文刷 GEO」；宣传单阶段不承诺自动生成视频 |
| 商业 | 前期免费 → 素材/案例资产归门店积累 → 后期按效果付费 |

**关键产品事实（文案必守）**

- **公开案例在公网**（官网/H5），不在小程序里给车主「逛案例」。
- **小程序**面向门店：沉淀透明化维修过程、生成案例。
- 对外避免主打「让 AI 信任 / 讨好模型」——易被理解成骗 AI；对外主语是**车主信得过**。

## 2. A4 拜访宣传单

### 2.1 场景与铁律

- 拜访时老板忙或不愿沟通，留下一页纸。
- **一页 A4、少字多图、疏朗**；密密麻麻即失败。
- 不信「客户已用 AI 找服务」的商家，可直接排除（筛选优先于说服）。

### 2.2 瘦身版结构（v2 共识，执行稿）

按优先级只保留：

1. **大标题**：客户已经开始用 AI 找服务了（无副标题）
2. **实事条**：豆包问答成交已收渠道服务费（如酒店约 12%，部分生活服务更高）+ 徽章「排序不靠广告费」「信号，不是唯一战场」  
   - 口径注意：是成交后**渠道服务费**，官方强调**不能靠付费改推荐排序**；汽修专属费率未按同级细则公示时，不要写死汽修佣金率。
3. **原理一条**：关键词 ✕ → 语义 ✓ → 可核对的真材料（旁注：AI 按意思找内容，不是数关键词）  
   - 信源金字塔、召回三步长流程、封闭生态大图、三支柱长说明：**不进此页**（口头或公众号深文）。
4. **主视觉**：发文 / 短视频（淡化）VS **案例资产** + 句「技术一变，形式就贬值；真案例才扛得住迭代」→ **辙见案例工具**（公众号码 + 小程序码）
5. **合作轴**：起步免费 → 透明化过程 → 按效果付费  
   - 「透明化过程」是门店自己该做的事（诚实、重体验），不是「配合辙见」。
6. **落款**：辙见 + 杭州盈简科技有限公司；**销售微信二维码**（不放电话）

### 2.3 曾讨论但故意不放进宣传单的内容

| 内容 | 去向 |
| --- | --- |
| 车主问答三格（保养/刹车片 → AI 答 → 推荐附近厂） | 可进公众号 |
| 封闭生态（各家内容互不相通）与全网布局 | 公众号深文 / 销售口述 |
| 信源分级细讲（政务央媒等）；不把「GEO 服务商」写成与央视同级 | 公众号深文；纸面只用「可核对真材料」 |
| 未来多终端（手机/家用机器人/智能家居/汽车）+ 绝对可信信源 | **公众号文章**，不塞 A4 |
| 自动生成视频 | 后续材料，本页不写 |
| 方案大对比表（软文 vs 广告 vs 辙见） | 销售口头或细册 |

## 3. 公众号规划（前 3 个月）

### 3.1 定位

- **对外一句话**：做让车主信得过的真实修车案例  
- **简介第二行（可选，给老板）**：门店可用小程序沉淀透明维修过程  
- **忌讳**：主打「让 AI 信任 / 优化到被模型点名」而像在骗模型  

### 3.2 运营规则

| 项 | 共识 |
| --- | --- |
| 号数量 | 只做一个号 |
| 写法 | **一文两用**：正文按车主能读完来写；文首或文末加商家注脚（这类内容才是车主会信的） |
| 主粮栏目 | ① 车主真问题 ② 真实案例拆解 ③ AI 找服务观察（少而精） |
| 节奏 | 周更 2 篇；趋势向大约每月 1 篇为基线，**缺真案例时可加**理念/趋势顶上 |
| 案例纪律 | **宁缺毋滥，绝不编造**；无授权真案例时改发真问题、透明修车示范（标明示范）、或 AI/趋势 |
| 文末三件套 | ① 讲清真实案例怎么生成 → ② **公网看案例** → ③ **商家去小程序做案例** |

### 3.3 前 8 篇题目清单（待写，已排期意图）

| # | 题目 | 类型 |
| --- | --- | --- |
| 1 | 修车案例怎样才算「真」？——我们怎么生成一条可核对的案例 | 机制说明 |
| 2 | 保养到底该多久做一次？别只听「到时间了」 | 车主真问题 |
| 3 | 刹车片有没有必要换？该看什么，不该听什么 | 车主真问题 |
| 4 | 一辆车的透明维修长什么样？（有真案例用真的；否则示范结构并标明） | 案例/示范 |
| 5 | 客户已经开始用 AI 找服务了——和修车店有什么关系 | AI/趋势 |
| 6 | 为什么「一直发短视频」也追不上？——技术一变，形式就贬值 | AI/趋势 |
| 7 | 事故后维修复盘：过程清楚，车主才敢信（优先真案例；无则延后） | 真案例 |
| 8 | 门店信息到处不一致，车主都会犹豫——先把「可核对」做好 | 真问题+轻机制 |

> 成稿尚未启动；改题目或调序时同步改本表。

### 3.4 公众号深文可写、纸面不写的主题（备忘）

- 未来 AI 终端（手机、家用聊天机器人、智能家居、汽车等）都可能成为推荐渠道  
- AI 要赢得人的信任，必须依赖绝对可信、可核对的信源  
- 语义检索 vs 关键词；召回后剔除难核实内容；信源权重（表述留有余地，勿伪造官方分级表）  
- 中国互联网生态封闭、内容互不相通 → 需自有案例资产 + 多平台分发，而非只做单一生态
