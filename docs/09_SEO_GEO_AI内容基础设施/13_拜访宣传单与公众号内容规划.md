| 不做 | 传统「靠发软文刷 GEO」；宣传单阶段不承诺自动生成视频 |
| 商业 | 前期免费 → 素材/案例资产归门店积累 → 后期按效果付费 |

**关键产品事实（文案必守）**

- **公开案例在公网**（官网/H5），不在小程序里给车主「逛案例」。
- **小程序**面向门店：沉淀透明化维修过程、生成案例。
- 对外避免主打「让 AI 信任 / 讨好模型」——易被理解成骗 AI；对外主语是**车主信得过**。

## 2. A4 拜访宣传单

### 2.1 场景与铁律

- 拜访时老板忙或不愿沟通，留下一页纸。
- **一页 A4、少字多图、疏朗**；密密麻麻即失败。
- **文案务实**：突出**引流、数字资产、免费**；**不写**语义检索、信源分级、佣金费率等技术/行业细节（那些留给公众号科普）。
- 销售口头仍可筛「完全不信客户找服务方式在变」的店；纸面本身以利益与动作为主。

### 2.2 务实版结构（当前执行稿）

1. **大标题 / Slogan**：**用最低成本，做出最经得起看的真案例**（可与「前期免费 · 可引流数字资产」并置或作主副）  
2. **体验段（开头，可稍长）**：请老板打开豆包，问「我想做个保养（或本店拿手项目），附近有哪些店靠谱？」→ 看推荐结果 → 点开参考链接，对照自己为何被推/没被推、别家凭什么被推。常见：抖音/头条有内容，或公网有曝光（甚至只有手机号）→ 收束一句：**AI 找店仍是蓝海**。紧接着一两句点明辙见：**帮你把真实维修过程变成案例资产，让店更容易出现在 AI 推荐里**（前期免费，案例归门店；呼应 Slogan：最低成本、经得起看）。  
3. **三利益块**：前期免费 · 数字资产（案例库归门店）· 方便引流（公网展示 / 可发各平台）  
4. **你得到什么**（短列表）：透明化修车顺便攒案例；案例归门店越用越厚；有了效果再谈按效果合作  
5. **扫码区**：公众号 + 小程序（大）  
6. **合作轴**：起步免费 → 沉淀案例 → 按效果付费  
7. **落款**：辙见 + 杭州盈简科技；**销售微信二维码**（不放电话）

### 2.3 故意不放进宣传单的内容（归公众号或口述）

| 内容 | 去向 |
| --- | --- |
| 豆包费率、排序不靠广告费等实事细讲 | 公众号 / 销售口述 |
| 关键词 → 语义 → 信源分级等原理 | 公众号（保持深度） |
| 封闭生态、多终端、GEO 概念辨析 | 公众号 |
| 发文/短视频 vs 案例的技术迭代论述 | 公众号；纸面不展开 |
| 自动生成视频、方案对比表 | 后续材料或口述 |

## 3. 公众号规划（前 3 个月）

### 3.1 定位

- **号的性质**：偏**科普**，不过多营销辙见产品本身  
- **品牌 Slogan（市场区分）**：**用最低成本，做出最经得起看的真案例**（对写手/买稿；强调工具化、过程完整）  
- **公众号对外一句话（读者信任）**：做让车主信得过的真实修车案例（与 Slogan 不冲突：经得起看 = 车主信得过）  
- **忌讳**：主打「让 AI 信任 / 优化到被模型点名」而像在骗模型；每篇硬广小程序  

### 3.2 栏目（主粮）

| 栏目 | 内容范围 |
| --- | --- |
| AI 趋势分享 | 模型本身的进步；AI 搜索 / 推荐趋势（含 GEO 认知） |
| 汽修案例分享 | 真实、可核对的维修案例（宁缺毋滥，不编造） |
| 汽修常识分享 | 保养、配件、决策类常识，服务车主阅读 |

### 3.3 运营规则

| 项 | 共识 |
| --- | --- |
| 号数量 | 只做一个号 |
| 写法 | 正文以读者能读懂的科普为主；可偶尔点明「真实、可核对」为何重要，但不写成产品说明书 |
| 节奏 | 周更 2 篇为参考；缺真案例时用常识或 AI 趋势顶上 |
| 案例纪律 | **宁缺毋滥，绝不编造** |
| 小程序 / 产品链接 | **按篇决定**：与「门店如何沉淀过程、生成案例」强相关时再放；纯常识、纯趋势篇可不放，仅留轻量署名即可 |
| 公网案例 | 谈「去哪里看真案例」时引导**公网**，不引导车主去小程序逛案例 |

### 3.6 公众号可深写、纸面不写的主题（备忘）

- 未来 AI 终端（手机、家用聊天机器人、智能家居、汽车等）都可能成为推荐渠道  
- AI 要赢得人的信任，必须依赖绝对可信、可核对的信源  
- 语义检索 vs 关键词；剔除难核实内容；信源权重（表述留有余地）  
- 中国互联网生态封闭、内容互不相通 → 自有案例资产 + 多平台分发
