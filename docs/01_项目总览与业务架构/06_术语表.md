# 术语表

> 版本：V2.0。与各端 V2.0 主 PRD 对齐，持续维护。

| 术语 | 含义 |
| --- | --- |
| **服务相册** | 门店为一次线下维修创建的结构化记录，含六阶段时间线、配件信息与确认留痕；V2.0 核心对象，替代「订单相册」为主口径 |
| **订单相册** | 旧版绑定平台订单的相册概念；V2.0 MVP **不实现**平台订单，文档中仅作历史对照 |
| **维修证据链** | 接车→检测→方案→配件确认→施工→交付的完整可追溯记录，含照片、确认、日志 |
| **配件告知确认单** | 独立结构化模块：配件名称、标准类型、价格对比、风险提示、车主勾选与确认时间 |
| **配件标准类型** | 原厂件、同质配件、品牌件、副厂件、再制造件、拆车件、修复件、翻新件、以修代换、未知来源件 |
| **非原厂件** | 除原厂件外的上述类型；须触发强提醒与车主确认 |
| **阻断式确认** | 未完成配件告知/关键照片等节点时，系统不允许进入施工或完工 |
| **关键凭证照片** | 包装、编码、新旧件对比、报价确认、车主确认、验收等；删除须留痕 |
| **证据包** | 一键导出的 PDF 维修记录，含时间线、确认记录、照片摘要、操作日志、校验码 |
| **案例档案** | 一次维修的托管单元：一种公开页，按材料显隐（概况 / 证据 / 单据 / 归属 / 问法）；不再等同于「一篇公开文章」或按工具分版式 |
| **公开案例** | 全球库中可打开的档案公开页。平台不背书真实性、不担保脱敏零残留 |
| **全球案例库** | 过底线的公开档案集合（含未认领）；首要给 AI 引用。见 [`15_` §7](15_案例档案与托管状态机.md) |
| **店页** | 某店橱窗：仅该店自己托管或已认领的档案 |
| **声称门店** | 未用门店身份提交时填写的店名+城市；机器归属必须是「声称、未确认」，不得写成该店案例 |
| **认领** | 门店同意将声称本店的档案挂上店页，并对该署名负责；原提交事实只读 |
| **星标** | 打在档案上的关注/认可（GitHub 式）；公开数字；不加总到门店；不是店铺评价 |
| **平台展示审核** | **废止作为上网条件**。对外禁止「已审核」。门店公开路径：已托管 + **隐私规则通过** + **店页说明已确认**；脱敏工具可选 |
| **辙见账号** | 案例站与自有工具（小程序、微信转案例等）共用的一套登录身份；用同一手机号或同一微信打通。门店/个人写在此账号上 |
| **推送登录** | 托管到案例站时必须登录辙见账号（类 GitHub push）。工具内干活不必先有此账号 |
| **来源 / 归属** | 推送时的案例库账号：已绑店 → 该店发布；未绑店 → 声称、未确认。废止「沟通记录转化 / 用户授权」对外标签 |
| **商家历史案例** | 商家上传的过往材料，统一标「商家上传」，不得称为平台订单案例 |
| **用户授权案例** | **已废止**（2026-09-03）。商家可改稿，授权标签不可靠；车主端不再提供授权公开 |
| **确认件** | 车主确认瞬间冻结的单据副本，不可静默覆盖；商家修订须另存 |
| **托管 / 取消托管** | 档案是否进入案例站托管库；与公开/不公开正交，见 [`15_案例档案与托管状态机.md`](15_案例档案与托管状态机.md) |
| **咨询线索 Lead** | 用户通过电话、表单、预约等留下的联系意向；**非平台订单** |
| **GEO** | 生成式引擎优化；城市+服务/车型/故障等组合页，承接搜索与 AI 引用 |
| **参考价/参考区间** | 仅作信息展示，不构成平台报价或成交承诺 |
| **平台说明** | 关键页声明：实际维修、报价、收付款、质保、售后由门店线下负责 |
| **风险等级** | 低/中/高，决定拍照、配件确认、签名、证据包等强度（对应 L1–L4） |
| **六阶段** | 接车记录、检测诊断、方案报价、配件确认、施工记录、完工交付 |
| **三套视图** | 车主视图、门店内部视图、争议/合规视图 |
| **翻译层** | 车主查看时将专业术语转为易懂文案 |
| **lifecycle_status** | 内容/案例 GEO 生命周期状态（实现字段，非订单状态） |

## 产品四件套（2026-09-03 修订，见 [`14_四件套产品架构与定位.md`](14_四件套产品架构与定位.md)）

| 术语 | 含义 |
| --- | --- |
| **辙见平台 / 案例站** | 维修案例**档案托管**站（`geo.simplewin.cn`，类 GitHub）。店页由门店控制；全球库可收未认领（不写成该店案例） |
| **辙见小程序（门店端）** | 案例**生产**工具：图文、单据、托管开关；微信群转案例迁入后同属此位 |
| **车主端小程序** | 确认单据、查看自有档案；**不做**公域授权发布 |
| **微信案例转换** | 群聊 → 完整相册+单据；一期官网导流，三期进小程序 |
| **GEO 体检工具** | `simplewin.cn/check` `/rank`；独立获客，不进案例站根路径 |
| **案例主权** | 店页收录由门店认领或自托管决定；未认领门店不能自摘名下架。平台不因托管取得所有权 |
| **默认私有** | 门店新档案默认不公开；公开须脱敏并确认将上网内容 |

### 命名纪律（对外文档与文案强制）

**绝不单独使用「辙见」二字指代其中任何一个。**

- 指托管平台 → 「**辙见平台**」/「**辙见案例站**」
- 指门店生产 → 「**辙见小程序**」或「**小程序门店端**」
- 指群聊整理 → 「**微信案例转换**」（归属小程序生产能力）
- 指诊断 → 「**GEO 体检工具**」
- 合称 → 「**辙见四件套**」或「**辙见平台与配套工具**」

## 已废弃或 MVP 不使用的术语

| 术语 | 说明 |
| --- | --- |
| 用户授权案例 / 用户授权发布 | 2026-09-03 废止 |
| 沟通记录转化（对外来源标签） | 统一为商家上传 |
| 已审核（对外案例 Tag） | 禁止；平台不审真实性 |
| 真实性机审硬门禁 | 2026-09-03 取消作为公开发布条件 |
| 平台订单案例 | V2.0 无平台交易 |
| 确认完工 | 交易履约概念，已删除 |
| 评价奖励 | 绑定订单的评价返现，MVP 不做 |
| 交易佣金 | 无平台订单，MVP 不做 |
| 草稿订单 | 旧版相册补订单概念，V2.0 以服务相册独立创建 |
| 六维评价（订单） | 交易完成后评价，MVP 不做；若未来做门店评价须非订单绑定 |
| 快速相册 | 可合并理解为「独立创建的服务相册」，不再强调补订单 |
