## 3. 本次并入的资产（已落盘）

### 3.1 批量扫描与城市榜单工具 → `scripts/geo-batch-checkup/`

- **是什么**：`checkup.py` —— 读门店表（xlsx）→ 10 个固定问题（9 品类 + 1 品牌词）→ 搜索后端（360 搜索为主，百度/必应/mock 可插拔）→ 五维打分（提及 30 / 位次 25 / 准确 20 / 地基 15 / 内容 10）→ SQLite 入库 → 一店一页 HTML + 榜单汇总页。
- **与 backend 两步体检的分工**：
  - 单店深检（拜访演示、逐项诊断）→ `public-geo-check`（已上线）。
  - 批量扫描（全城门店跑分、出榜单、攒白皮书数据）→ `scripts/geo-batch-checkup/checkup.py`（本次并入，独立脚本）。
  - 后者是前者的「数据采集器」，前者是后者的「面谈演示器」。两者结论口径一致：可见性分数 = 抽样检索结果，不是全网公证。
- **首期数据（2026-08-29，61 家杭州门店，610 次真实查询）**：
  - 平均 20.2 / 中位 19 / 最高 41 / 最低 0；
  - **60/61 家品类词零提及**（车主问「杭州修变速箱哪家好」没一家出现）；
  - 55/61 家品牌词有收录（多为工商/招聘类页面）；
  - 唯一被品类词提及的是拱墅区莱恩汽车（58 同城聚合页第 4 位）。
  - 核心叙事：「门店活在工商档案里，死在车主提问里」——正是 GEO 服务的价值主张。

### 3.2 微信群一键归档工具 → `scripts/geo-case-archive/`

- **背景**：小程序冻结新功能，但案例生产不能停。多数门店现用微信群（客户+技师拉群发图解释）替代软件。
- **是什么**：`archiver.html`（本地解析器：粘贴微信复制的群聊文本 → 自动识别发言人/内容/[图片] 计数 → 生成六字段案例草稿）+ `微信群归档操作手册.md`。
- **三条合规路径**（微信无官方导出，自动化插件是封号灰产）：
  - A 复制粘贴（电脑微信多选复制，盈简代录，主力）；
  - B 截图投递（师傅手机截图发归档号，保底）；
  - C 逐条转发归档号（师傅多选逐条转发，盈简统一处理）。
  - **禁用「合并转发」**（折叠卡片内容拿不出来）。
- **六字段标准**（与 `h5/fixtures` 案例结构对齐）：车型 / 症状 / 方案 / 工期 / 价格区间 / 照片（症状·配件编码·完工）。
- **三级信源标签**：商家提供 → 实地核验 → 车主确认（施工记录发车主微信确认后升级）。
- **价值定位**：不替代微信群（输入赢了），做群的「沉淀出口」（输出端：结构化 + AI 可见 + 可导出）。对应 §2.1「真案例生产」在小程序冻结期的过渡手段。

### 3.3 数据报告素材 → `docs/13_市场物料/`

- **大势数据点（2026-08-29 搜集，含来源）**：79.4% 城市消费者购物前咨询 AI（中小商业企业协会 2026Q2）、AI 对消费决策影响力 43.7% 首超传统广告（42.6%）、豆包 MAU 3.82 亿、84.56% 试过 AI 选购但负面反馈主导（上海消保委 618 报告，4308 份问卷）等。
- **报告骨架（五章）**：摘要 / 大势（引用公开数据）/ 现状（61 家可见性扫描）/ 需求侧（车主问卷，投放中）/ 建议与脱节度实验。
- **三源组合策略**：大势公开数据 + 独家可见性扫描 + 车主问卷（线上投放 + 门店扫码补充真实车主样本）。
- **一份报告三角色**：教育引子（让商家信趋势）+ 自证案例（让商家信你）+ AI 引用实体（让 AI 信你）。发布路径：simplewin.cn 官网首发 + 公众号/知乎同步。

## 5. 文案与信任红线（从讨论沉淀，写入本文即生效）

1. 收的是**体检和施工的钱**，不卖排名；榜单是算出来的，规则公开可复算，「算得不一样欢迎公开打脸」。
2. 商家买到的是**施工**（体检、纠错、案例建设、监测），不是**结论**；服务协议写明「不对排名结果作承诺」。
3. 案例区是**证言级信任**（证据链 + 时间积累），打分区是**数据级信任**（可复算）；**绝不用打分的可复算性给案例背书**。
4. 案例页明示信任等级：「本案例由门店委托发布，经盈简核验证据链，不代表盈简对门店整体服务质量作担保」。
5. 早期案例宁缺毋滥：只发证据链完整的真案例；查实造假 → 全网公示 + 撤案 + 退费。
6. 对外不自我标榜「中立」，用「透明」「可验证」；盈简自己的官网可见性也按同一套规则公开打分（自我审计）。
