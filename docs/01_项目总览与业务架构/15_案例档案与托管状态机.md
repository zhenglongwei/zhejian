# 案例档案与托管状态机

> **生效**：2026-09-03  
> **状态**：产品口径定稿 · 二期实现主真源  
> **配套**：[`14_四件套产品架构与定位.md`](14_四件套产品架构与定位.md) · [`19_商家发布案例上网口径.md`](../04_维修过程相册/19_商家发布案例上网口径.md)

---

## 1. 对象

**案例档案（Case Archive）**：一次维修对应的托管单元，含：

- 原始图文（过程证据）
- 面向车主单据（报价表、工单、维修确认单、质保单、车辆维修报告等；三期产品化）
- 概况说明（商家填写，AI 可辅助）
- 本单 FAQ（AI 可辅助，商家确认）

公开页三层：概况+脱敏图文 → 脱敏单据 → FAQ。

---

## 2. 状态维度（正交）

| 维度 | 取值 | 含义 |
| --- | --- | --- |
| `hosted` | false / true | 是否托管到案例站 |
| `visibility` | private / public | 是否公域可见（仅 `hosted=true` 时 `public` 有意义） |
| `desensitizeApplied` | false / true | 当前公开稿是否已跑过脱敏并经商家确认 |
| `authenticityCommitmentAt` | null / ISO | 商家勾选真实性承诺时间（公开必填） |

约束：

- `visibility=public` ⇒ `hosted=true` 且已脱敏确认且已承诺。  
- 取消公开：`visibility=private`，`hosted` 可仍为 true（私密档案仍在库）。  
- 取消托管：`hosted=false` 且 `visibility=private`；公域 URL/索引下线；生产侧小程序仍可保留本地档案。

---

## 3. 主流程

```text
小程序生产（图文 / 单据 / 微信转案例）
    → [托管] hosted=true, visibility=private（默认）
    → 可选：使用脱敏工具（默认勾选）
    → [设为公开]
         → 强制脱敏 → 商家预览/修改
         → 填写概况（AI 可辅助）→ FAQ 草稿（AI 可辅助）
         → 勾选真实性承诺
         → visibility=public，写入公开稿 + 最近更新时间
    → [取消公开] visibility=private（档案仍托管）
    → [取消托管] hosted=false，公域净空
```

平台投诉/违诺下架：等同 **取消公开**，不硬删。

---

## 4. 确认件与修订

| 对象 | 规则 |
| --- | --- |
| **确认件** `immutable_revision` | 车主确认瞬间冻结；不可静默覆盖；公开可展示并标确认时间 |
| **商家修订** `draft_revision` / 公开稿 | 可随时改；保存公开须另存版本；不得覆盖确认件字节 |
| **公开页** | 展示商家确认后的**最新公开稿**；确认件可并列或折叠；页脚「最近更新」 |

平台不审核修订与确认件是否一致。

---

## 5. 与旧「CaseSnapshot 整案冻结」关系

- **废止**：公开后整案永久不可改、H5 只读防 drift（整案级）。  
- **保留精神**：车主确认过的单据副本不可篡改。  
- 实现上逐步将 snapshot 语义收窄为确认件 + 公开稿版本；卷九相关 skill 以本文为准修订。
