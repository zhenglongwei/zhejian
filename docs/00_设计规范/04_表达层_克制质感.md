## 0. 这份文档解决什么

`00_设计体系` 是一套优秀的**约束系统**（token 完整、纪律严明、大量"禁止项"），它保证全站"干净、一致、合规"。但"像大牌设计师的产物"来自另一层——**表达系统**：字体性格、色彩温度、版式节奏、深度语言、图标基准、动效手感。那一层过去几乎没规范。

本文补上这一层。**核心信条一句话：克制 = 精确，不是少做。** 高级感不来自加装饰，而来自把每个值定死、杜绝"顺手写的数"，让屏幕上没有任何一处是意外的。

定位边界（与 `00_设计体系` §2 一致，不破）：辙见仍是**克制的服务相册工具**，不是促销传单。本文追求的"大牌感"是 **Apple / 无印良品式**：留白、中性、单一强调色、细节做到极致——**不是**炫酷渐变 / 深色炫技那一路。

## 1. 使用规则（先读这段）

1. **新页面优先读 `--craft-*`**；旧页面继续读 `--color-*` / `--font-*`，**两套并存不冲突**，不强制一次性回改。
2. **同页不混温**：一个页面里，中性色要么走 `--color-*` 要么走 `--craft-*`，不交叉（否则灰阶出现两种温度，正是要消灭的"意外"）。
3. **迁移映射**（旧 → 新）见 §7；映射后再谈组件重构。
4. 品牌改色只动 `--color-primary`，`--craft-accent` 继承自它，**自动跟随**，禁止在 craft 层写死品牌蓝。

## 2. 六条设计主张

> 每条：主张 → 现状掉价信号 → 规则 → 关键令牌。视觉对照见商家工作台旗舰屏样机（表达层提案）。

### C1 · 字体承担 70% 高级感

- **掉价信号**：无展示字、无字距体系，字号 7 档混用无模块比例。
- **规则**：全页只用 **4 档字号 + display**；大数字（车牌 / KPI / 报价）用 display 处理——紧字距 `-1rpx` + `font-variant-numeric: tabular-nums` 等宽对齐；数字、时间、张数一律等宽。系统字足矣，克制派靠排版不靠花字。字重止于 600（沿用 `00_设计体系` §5.2）。
- **令牌**：`--craft-font-*`、`--craft-track-tight`、`.craft-figure`、`.craft-kicker`。

### C2 · 亮蓝大 Banner → 近白卡 + 一条品牌细线

- **掉价信号**：门店扉页用三段式亮蓝渐变 `--color-mch-hero-start/mid/end`，促销 App 感压过内容。
- **规则**：扉页 / Hero 头图改为**同温表面卡 + 左侧 3rpx 品牌细线**（或单色低对比渐层），把"颜色压场"换成"留白与层次撑场"。主色蓝可着色面积 ≤10%。
- **令牌**：`--craft-surface`、`--craft-line`、`--craft-accent`（仅细线 / 关键数字）。

### C3 · 深度用耳语，不用阴影团

- **掉价信号**：`--shadow-mch-card: 0 16rpx 48rpx` 过重，满屏投影。
- **规则**：卡片默认 **1rpx 发丝描边 + 极浅投影**；**能用描边 / 色层分离就不投影**；投影只留给浮层、抽屉。分离层次优先靠 `--craft-surface` vs `--craft-canvas` 的同温微差，而非拉开明度。
- **令牌**：`--craft-elev-1`（卡）、`--craft-elev-2`（仅浮层）、`--craft-line`、`.craft-card`。

### C4 · 圆角收敛成一套

- **掉价信号**：8 / 16 / 24 / 40 / 48 / 999rpx 混用。
- **规则**：卡片 `28`、面块 `24`、控件 `18`、胶囊 `999`。同层元素同圆角；不再出现第三种数。
- **令牌**：`--craft-radius-*`。

### C5 · 图标是真线稿，不是滤镜凑

- **掉价信号**：给彩色 PNG 打 `grayscale + brightness + sepia` 滤镜假装统一（`--color-nav-icon-well` 配套、`tokens.wxss` 里的 `nav-icon-tone-album` hack）——**全站最掉价的一处**。
- **规则**：重画一套**单色等线 SVG 图标**：统一线宽 `--craft-icon-stroke: 3rpx`、圆角端点、同一光学尺寸与网格；语义色只给底块，不给线本身。**移除滤镜 hack**。
- **令牌**：`--craft-icon-stroke` / `--craft-icon-size` / `--craft-icon-well`。

### C6 · 数据即设计 + 单一强调色

- **掉价信号**：工作台数据密集却无图表语言；功能色滥用于步骤 / 装饰。
- **规则**：把"近 7 天 / 待办"做成**极简迷你图**（细线 / 细柱、弱填充、无网格噪点）；**全页只有蓝可点**；功能色只表**结果**（成功 = 已交车 / 资料齐），**不表步骤、不作进度**（沿用 §5.2 时间线圆标规则）。
- **令牌**：`--craft-success/warning/danger`（降饱和）、`--craft-accent`、`--craft-accent-tint`。

### C7（动效 · 伴随）· 快而内敛

- **规则**：只用 `transform` / `opacity`；时长 150–220ms；标准缓动；KPI 数字缓升、列表交错入场、抽屉用 `--craft-ease-out`。**禁止**弹跳过冲、全屏闪动、自动轮播（沿用 `00_设计体系` §12.4）。
- **令牌**：`--craft-dur-1/2`、`--craft-ease-std`、`--craft-ease-out`。

## 5. Do / Don't

**Do**

- 用发丝描边 + 同温微差分层；用留白拉开模块。
- 数字用等宽 + display 处理；全页只留一个蓝作"可点 / 当前"。
- 图标走统一线宽 SVG。
- 改品牌色只动 `--color-primary`。

**Don't**

- 不贴三段亮蓝大 Banner、不大面积铺主色。
- 不混用两套灰阶温度；不写第 5 种圆角 / 裸 `font-size` 数字。
- 不给彩色 PNG 打灰度滤镜充当统一图标。
- 不用功能色表示步骤 / 进度（绿只表结果）。
- 不重新发明一套促销视觉；不引入 craft 层之外的新色。

## 6. 验收问句（每个 craft 页 PR 前）

- 删掉所有彩色，只剩中性 + 一条蓝，这屏还成立吗？（应成立）
- 屏幕上有没有任何一处"数"是表上查不到的（字号 / 圆角 / 间距 / 色）？
- 数字是否等宽对齐？大字是否紧了字距？
- 层次是靠描边 / 色层，还是又堆了重投影？
- 图标是不是真线稿、统一线宽？滤镜 hack 是否已清？
- 功能色有没有被误用成步骤 / 进度色？
