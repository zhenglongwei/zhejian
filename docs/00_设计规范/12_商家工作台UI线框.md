## 0. 与用户端工具台对照

| 维度 | 用户端 `pages/mine/index` | 商家端 `workbench/index` |
| --- | --- | --- |
| 定位 | 车主翻阅服务相册 | 门店生产/管理服务相册 |
| 壳层 | `showBand=false` | 同左 |
| 扉页 | `ui-mine-user-header`（用户） | **`ui-merchant-store-header`**（门店） |
| P0 Hero | `ui-album-card` ×1～2 `audience=user` | **`ui-album-card` ×1～2 `audience=merchant`** |
| 待办 | 仅有待办时一块；**仅咨询待处理** | 咨询待处理 + **评价待回复** |
| 次要 | 公示激励弱条、H5 弱链 | 案例动态 P1、GEO 弱条（条件） |
| Dock | **3 格** | **4 格**：新建相册 / 咨询线索 / **车主评价** / 服务方案 |
| 管理 | 主账号 · 页内文字链 | 门店主页 · 编辑资料 · 员工管理（评价已上 Dock） |

**north star**：与用户端同一套「单页工具台」容器语法；差异在 **内容**（门店 vs 车主），不在卡片样式分叉。

### 1.1 Hero · 服务相册

| 项 | 规则 |
| --- | --- |
| 组件 | `ui-album-card`，`audience="merchant"`，`showProgress="{{true}}"` |
| 拣选 | **进行中优先**（维修未结束，按更新时间最多 **2** 本）；**无进行中**时只展示 **最近 1 本**（可含已完工），不叠两本完工 |
| 数据 | `enrichMerchantAlbumListItem`；须含 `coverUrl`（与列表页一致） |
| 区头 | 「服务相册」+「全部 ›」→ `album/list` |
| 角标 | 无（相册进度见 Hero 卡） |
| 空态 | `ui-empty` +「新建服务相册」 |
| 禁止 | sticky 大待办卡内嵌主按钮；无封面的纯文字摘要作 Hero；无进行中时堆 2 本已完工 |

### 1.2 待办聚合

| 项 | 规则 |
| --- | --- |
| 展示 | **无待办时整块不渲染** |
| 样式 | 对标 `mine__todo`：headline + 圆点 + `text-caption` + › |
| 顺序 | ① 咨询待处理 ② **相册待补留证**（`pendingUpload`）③ 评价待回复 ④ 回访跟进 |
| 项 | `pendingLeads` →「N 条咨询待处理」；`pendingUpload` →「N 本相册待补留证」；`pendingReviews` →「N 条评价待回复」；`pendingFollowUp` →「N 项服务待回访跟进」 |
| 点击 | 咨询/评价进对应列表；待补留证 / 跟进：1 本直达编辑，多本 ActionSheet |
| 禁止 | 彩色左边框告警行；`0 条` 占位行；本轮不把「待车主发布 / 案例审核中」塞进待办 |

### 1.3 快捷入口（Dock + 文字链 · 单卡）

**Dock 四格**（2026-08-02 · REV-MOD：车主评价必显）

| key | 标签 | 跳转 | 角标 |
| --- | --- | --- | --- |
| `createAlbum` | 新建相册 | `album/create` | — |
| `leads` | 咨询线索 | `lead/list?tab=pending` | `pendingLeads` |
| `reviews` | 车主评价 | `review/list?tab=pending` | `pendingReviews` |
| `services` | 服务方案 | `service/list` | — |

视觉：`mine__dock` 同款；**一张** `section--panel` 包裹 Dock + 下方文字链，禁止第二块宫格卡。

**数据概览**：不占 Dock；扉页 `overviewLine` 仅拼**非 0** 段（近7天咨询 · 透明度）；全空则不展示该行；点击 → `dashboard`。

**主账号文字链**（Dock 下方分隔线 + `text-link`，非 icon 宫格）

| key | 标签 | 跳转 |
| --- | --- | --- |
| `storeHome` | 门店主页 | 用户端门店详情（预览/分享） |
| `staff` | 账号管理 | `staff/list` |

扉页已支持切店时：**不**再放「切换门店」文字链。非主账号：仅 Dock，无文字链。

### 1.4 案例动态与 GEO / 套餐

| 块 | 规则 |
| --- | --- |
| 案例动态 | 有 `recent` 才渲染；**最多 2 条** |
| GEO 弱条 | **条件展示**：机会服务名须落在本店近期相册 `serviceName` 或在架服务名集合内；对不上则整条不渲染（宁可不显示，也不推无关类目） |
| 套餐说明 | **首页不单独占行**；说明入口 = 扉页「免费使用」Tag 点击 → 套餐页 |

## 5. 禁止清单

- 页内重复「服务相册 · 汽车维修档案」band  
- 首屏 5+ 同级大阴影卡片平铺  
- Hero 无封面纯文字行（除非 API 降级且文档注明）  
- 待办 `0` 条仍展示  
- 顶栏「开启微信通知」主入口

## 6. 验收要点

1. 与用户端首页并看，容器节奏一致（扉页 → Hero → 待办 → 案例 → Dock）。  
2. Hero：**进行中优先**；无进行中仅 1 本；卡片与商家相册列表视觉一致。  
3. 无待办时无待办块；待办含咨询 / 待补留证 / 评价 / 跟进（有数才出）。  
4. Dock 四格可点通；主账号文字链无重复切店；扉页非 0 概览可进数据看板。  
5. GEO 弱条仅当机会类目与本店服务相关；套餐说明仅 Tag。  
6. `design-system-check` 无散落硬编码色值。
