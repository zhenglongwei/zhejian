# Skill: 商家进度 · 传图→打码→识图→成项

> Agent 入口：`.cursor/skills/merchant-flow-photo-pipeline/SKILL.md`  
> 真源：[`../04_维修过程相册/26_商家端事件节点与单据节点链流程.md`](../04_维修过程相册/26_商家端事件节点与单据节点链流程.md)  
> 引擎实现另走 `desensitize-engine`；公开链另走 `privacy-desensitization-check`

## 目标

接车 / 检测 / 工单：**连拍同一套**；传完先打码、再识图、再成项。改任何一截都必须把「只打本批、不等整本、删项进图库、工单按件、图跟项身份走」收到所有入口，禁止改一处宣称做完。

## 使用场景

- 工单/检测归组慢、超时、「网络异常」
- 重复打码、后一步又打前序图
- 删项后又拼回、图库里找不到刚卸下的图
- 工单一项吞掉不同件；找不到「加一项」
- 增删检测项/施工项后，图从正确项跑到别的项
- 用户再说「这个问题不是改过了吗」

## 硬规矩（产品语言）

1. **接车、检测、工单同一套连拍。** 项内加号只补图、不识图。
2. **只打、只识本批还没有成功标记的新图。** 前序节点只带已经写下/识出的**文字**，不附图、不重认。
3. **归组只等这一批新图码完。** 禁止等整本相册打完、禁止为刷新整本名单/扫假打码挡住识图。整本名单后台补。
4. **打码成功就留下标识；引擎升级、案例预览、授权预览不得重打已成功图。** 同一张正在打的，合并等待，不打第二遍。
5. **删项 / 删未归组图：** 该项文字和挂图从本步拿掉；文件留**本单图库**，不删对象存储、不删库行。空列表不得用库里的散图把项拼回来。再用从图库勾选。
6. **工单按换成了哪一件归组**（如下摆臂、前杠），不用方案套餐全称把不同件塞进一项。对得上方案只做标记，项目名仍写件名。用料预填「换了什么件」。
7. **「加一项」必须能看见。** 拍照加号只传未归组；加一项是空项手填。两者不能合成一个「+」。
8. **图跟项身份走，不跟「第几项」走。** 这是 `object-model-first` 在检测/工单上的实例；真源 `26` §6.3～6.5。一项是一个完整对象：自己的稳定编号、部位名、挂图都住在一起。增删、改名、换图、换顺序，图仍挂在该项上。禁止用第几项、展示顺序、图片地址、部位名把字和图重新对在一起（部位可重名）。页面列表卡片身份必须用该项稳定编号，不能用第几项——否则删中间一项或点「加一项」时，后面卡片会把别人的图显示出来。存量「一图一项按下标对一次」只允许迁移时用一次，生成编号后不得再走。
9. **认隐私用小图，打码和识图用原图。** 缩小图只进阿里云车牌/人脸/车架号识别；禁止进成项识图、禁止当相册原图。打码一张接一张。禁止把杭州桶地址交给上海识别。

## 两套脱敏不要混

| 场景 | 图 |
| --- | --- |
| 阿里云认车牌/人脸/车架号 | 缩小 JPEG（不进相册） |
| 识图、公开、分享 | 打码后的原尺寸图 |
| 本单车主看自己相册 | 可以完整车牌 |
| 商家归组闸 | 本批新图有打码成功标识即可，不是整本就绪 |

## 收口搜索（改完必须做，结果写进验证）

至少搜这些，有命中则说明为何不挡归组 / 为何不重打 / 为何不删文件：

- 整本就绪、`getAlbumPreMaskReadiness` 是否被归组/识图调用
- 假打码整本扫描（`collectStubRawUrlKeys` / `preMaskTaskHasStubArtifacts`）是否挡整理
- 保存后是否对**整本**再跑打码引擎（已成功图必须复用）
- 卸下项上的图是否 `deleteMany` 相册图行（应改挂图库，不删行）
- 空 findings 是否用相册散图回填项
- 工单项目名是否被方案套餐全称覆盖
- 页面是否绑定「加一项」（不能只有 JS 没有入口）
- 增删项后图是否按下标/URL/部位名重对（须按项 `id`；图只住在该项 `images[]`）
- 列表卡片 `wx:key` / `listKey` 是否用第几项（须用 finding `id`）
- `syncFindingsWithImages` 一类「一排图对一项」是否仍被检测/工单主路径走到

## 验证

| 项 | 过法 |
| --- | --- |
| 检测 vs 工单张数接近 | 归组等待接近，工单不得再等整本 |
| 删项 | 项没了；图库还在；再进本步不复活 |
| 加一项 | 项列表下（无项时在拍照加号旁）能点出空项 |
| 工单归组 | 按件拆开，用料有字 |
| 增删项后图不串 | 中间插一项、删一项、改名后，各卡仍是原来那几张图 |

须真机的标「待你点验」，不要说全部完成。

动手后：搜索结果摘要 + 待点验路径。
