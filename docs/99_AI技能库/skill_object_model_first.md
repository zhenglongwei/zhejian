# Skill: 数据结构与对象边界（写码前必过）

> Agent 入口：`.cursor/skills/object-model-first/SKILL.md`  
> 配套：`feature-build-verify`（需求对齐之后、拆功能之前）· `docs-before-code` · `invariant-close-loop`  
> 检测项+挂图实例：`merchant-flow-photo-pipeline`（真源 `26` §6.3～6.5）  
> 打码结论住哪：`node-mask-state-machine`

## 目标

**写任何非 trivial 代码之前，必须先想清楚数据结构。**  
流程节点读错、显示错、可公示图对不上、AI 分析反复解析失败——根因几乎都是：流程 / 节点 / 图片 / 报告 / 大模型返回的形状没有定死，多处各写各的。

用产品语言写清：**数据住哪、谁写谁读、身份是什么、外形是否固定**；再拆任务写码。禁止按页面上一排卡片去排两个数组，再用第几项把字和图对上；禁止「模型随便吐 JSON、前端多套 fallback 猜」。

## 使用场景

- 新增或改一类可增删改的东西（检测项、施工项、接车分类、方案行、相册节点……）
- **流程、节点、节点内图片、单据/报告** 的读写与展示
- 一项里要挂图、挂金额、挂结论，或两端各自展示同一对象
- **接入或改大模型 / OCR / 归组**：返回结构会进库或进页面
- 用户提到：增删后对错了、串项、读节点却显示空、同名两项并成一项、解析总失败
- `feature-build-verify` 第 1 步发现会动对象或读写路径

**可跳过**：改一个错字、只改文案、已批准方案下的机械改字段名、对象与读写路径文档已写清且本轮不改。

## 动手前必须答清（产品语言，写进方案给用户看）

### A. 业务对象（有增删项时必答）

1. **什么算一个对象？** 一句话说清边界。例：一项检测 = 部位 + 挂图 + 检查结果 + 检查发现；不是「第几张图」也不是「第几行卡片」。
2. **身份是什么？** 改名、换顺序、中间插入、删除之后，还是不是「同一个」。**默认不是身份**：展示顺序、名称、图片地址。名称可重名、可改，不能当主键。
3. **什么住在对象里面，什么只引用？** 同生共死的放进去（图跟该项）。可卸下、可进本单图库、可被多项共用的，用身份去挂，不要复制成另一套平行名单再按下标对。
4. **哪些操作不能把关系拆乱？** 至少写：加一项、删中间一项、改名、换图、换顺序、两端各自展示。列表认卡片必须用该项自己的稳定身份，不能用第几项。
5. **旧数据怎么迁一次？** 允许「打开一次按旧形状生成身份并落库」；禁止每次读取都按下标再对一遍。

### B. 读写路径（动流程 / 节点 / 图 / 报告时必答）

6. **正文住哪？** 例：服务过程图与节点内容在流程节点里；单据信封不是过程图真源。一句话说清「页面/接口读的那一份」。
7. **谁写、谁读？** 列出写入入口与读取入口（预览、硬拦、打码、公开页是否同一套收集函数）。禁止预览读 A、闸门读 B。
8. **有没有第二份副本？** 有则说明是否废止、迁移还是经用户确认保留；未经确认不得擅自「先留兼容」。

### C. 外部返回形状（接大模型 / 不稳定上游时必答）

9. **约定的成功外形是什么？** 固定字段名、类型、嵌套；写进 docs 或单测夹具。成功只认这一形。
10. **不合形怎么办？** 记失败 / 重试 / 人工，**禁止**多层猜字段、多套 fallback 把半残数据当成功。
11. **谁负责校验？** 入库前校验；解析失败要有可观测痕迹（原文 + 错误），不要静默成空对象。

未写清适用条目，**不准进入功能拆分和写码**。用户确认方案后，先把口径写入对应 `docs/`（及必要时 `docs/11_数据结构与状态机/`），再写代码。

## 反模式（禁止）

- 两个数组（一排字、一排图）用第几项对齐
- 用部位名 / 项目名合并两项
- 用图片地址反查「这是哪一项」
- 页面列表用第几项当卡片身份（增删后后面卡片会显示别人的图）
- 空列表用库里散图把项重新拼出来
- 只改这一页的数组形状，读写接口、另一端、归组结果仍按下标对
- **预览读节点、闸门/打码仍读旧表或单据 payload**
- **大模型返回不定形，靠多套解析「碰运气」**
- 未定读写路径就先写页面「能显示一点」

## 收口搜索（改完必须做）

至少搜：按下标配对、用名称当主键、用图片地址反查项、列表卡片身份用第几项、把一排图重生成项、第二真源读旧表/payload、对 LLM 输出的宽松猜字段。有命中须说明为何安全，或改掉。搜过什么写进验证，没有清单不准说做完（`invariant-close-loop`）。
