案例主权

案例是门店的，不是我们的

门店对自己的案例拥有完整处置权：

  • 保存到辙见 / 不保存（托管：是否把档案放在辙见上）
  • 公开 / 不公开——公开须先确认已脱敏；默认不公开
  • 下载 / 删除——分期提供；下架只是不再公开，档案仍可自己留着
  • 来源——对外只写「商家上传」

公开前须门店确认已脱敏并勾选真实性承诺；平台不做线下验真，车主仍以到店为准。

四件套怎么配合

记下是一回事，公开是另一回事

小程序负责把这一单记清楚；案例站负责需要时再公开：

  • 辙见小程序（门店端）——拍过程、出单据；也可把微信群聊整理进同一本相册
  • 微信转案例——在小程序里粘贴群聊、一次选图，核对后再决定是否公开

做出来的记录可以放到辙见上，也可以不放。像剪映剪完的片子，不一定要发抖音。

案例长什么样

六字段，一个都不编

每条案例来自门店真实维修过程，六个字段固定：车型 / 症状 / 方案 / 工期 / 价格区间 / 照片。车主到店前能对上号，AI 引用时能对得上事实。

不编故事、不夸大、不替门店承诺。案例要经得起车主到店核对。

隐私：车牌、手机号、人脸等信息在生成环节自动过滤。公开前须门店确认已脱敏；公开页提供投诉入口，接到通知立即下架。
