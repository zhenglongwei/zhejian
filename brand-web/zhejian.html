辙见

辙见是案例上传与公开产品。你可以把真实案例保存下来，再决定是否公开。

现阶段主要面向修理厂商家；产品方向是支持更多用户上传。

案例主权

案例归上传者

可自行决定是否公开；公开前须按规则脱敏并确认。平台不因保存取得内容所有权。

  • 保存 / 不保存——是否把案例放到辙见上
  • 公开 / 不公开——公开须先确认已脱敏；默认不公开
  • 下载 / 删除——分期提供；下架只是不再公开
  • 来源——对外标注上传者

公开前须上传者确认已脱敏并勾选真实性承诺；平台不做线下验真。

把这一单的文字整理进相册：微信扫码打开「从聊天创建」

记下与公开

记下是一回事，公开是另一回事

小程序负责把这一条记清楚；案例站负责需要时再公开：

  • 辙见小程序——现阶段主要给修理厂商家拍过程、出单据；也可把聊天或文字整理进同一本相册
  • 从聊天创建——在小程序里粘贴文字、一次选图，核对后再决定是否公开

做出来的记录可以放到辙见上，也可以不放。

案例长什么样

汽修场景：六字段，一个都不编

在汽修场景，一条案例固定包含：车型 / 症状 / 方案 / 工期 / 价格区间 / 照片。其他行业的字段会随品类扩展，不以门店为唯一模板。

不编故事、不夸大。公开前须确认已脱敏；公开页提供投诉入口。
