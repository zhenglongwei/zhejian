辙见平台

汽修案例托管站。小程序负责生产档案，案例站负责托管——像 GitHub 托管代码一样，门店托管自己的维修案例。

案例主权

案例是门店的，不是我们的

门店对自己的案例拥有完整处置权：

  • 托管 / 取消托管——是否进入案例站托管库
  • 公开 / 不公开——公开须强制脱敏并预览确认；默认私有
  • 下载 / 删除——分期提供；下架仅取消公开，档案仍可私密保留
  • 来源——对外仅标注「商家上传」

平台不审真实性、不担保脱敏零残留。微信群转案例能力迁入小程序门店端（见 说明页）。

四件套怎么配合

托管是一回事，生产是另一回事

辙见平台管「存和发」，案例由生产工具做出来：

  • 辙见小程序（门店端）——拍过程、出单据；也可把微信群聊整理进同一本相册
  • 微信转案例——在小程序门店端粘贴群聊、一次选图，产出完整相册后再决定是否托管

做出来的案例可以托管到辙见平台，也可以不托管。类比很直接：辙见平台像抖音，小程序和微信工具像剪映——剪映剪完的片子不一定要发抖音。

案例长什么样

六字段，一个都不编

每条案例来自门店真实维修过程，六个字段固定：车型 / 症状 / 方案 / 工期 / 价格区间 / 照片。车主到店前能对上号，AI 引用时能对得上事实。

不编故事、不夸大、不替门店承诺。案例要经得起车主到店核对。

隐私：车牌、手机号、人脸等信息在生成环节自动过滤。公开前须门店确认已脱敏；公开页提供投诉入口，接到通知立即下架。
